表面：模糊与可读文字

macOS 的毛玻璃效果在全站只有一个来源：系统令牌。你手写 blur(12px)，用户的「模糊等级」设置就对你失效——所以 static-check 会直接判失败。源码：src/javascripts/surface.js。

这是什么

系统设置里有一个「模糊等级」滑块（5 档：关闭 / 极轻 / 轻柔 / 标准 / 浓重，对应 0 / 4 / 8 / 12 / 18px）。 它改的不是某个具体元素，而是一组 CSS 变量：--surface-blur-1 到 --surface-blur-5（按角色分的五档，倍数 1 / 1.75 / 2.75 / 4 / 6.5）。 你的界面只要引用令牌，等级切换就对你自动生效；手写像素值，你就脱离了这套系统。

CSS 侧正确写法

backdrop-filter: blur(var(--surface-blur-3));   /* 角色档 1-5：3 是常规面板，5 是启动台那种全屏重素材 */
color: var(--surface-text);                     /* 主题面板档文字（菜单 / 弹层 / 提示条） */
color: var(--surface-text-wallpaper);           /* 墙纸档文字（背后就是墙纸的表面） */
令牌用途
--surface-blur-1 … --surface-blur-5模糊半径五档（系统按用户等级统一赋值）
--surface-text*主题面板档文字色：判定输入是面板底色；菜单 / 弹层 / 提示条不吃墙纸着色
--surface-text-wallpaper*墙纸档文字色：背后就是墙纸的表面（全屏浮层、开着墙纸着色时的侧栏 / 控制中心 / 预览 chip）

「切档」不需要 JS 登记：在样式表的 html[data-wallpaper-tint="on"] 规则里把四条 --surface-text* 指向 --surface-text-wallpaper* 即可（自定义属性沿继承树生效）。

带侧栏的窗口：分两块表面

  • 窗口根 background: transparent，实色只铺内容区，侧栏用半透明档做真毛玻璃（参照 mods/finder/style.css）。
  • 如果在窗口根铺实色，等于在侧栏背后垫了一块平色板——backdrop-filter 糊的只是自家底板，墙纸透不上来。
  • 别在窗口根写 isolation: isolate：它会把根变成 backdrop root，采样范围被截进窗口内部。

墙纸着色：浓度必须真的乘上

每条墙纸着色规则的固有浓度要写成 calc(<固有浓度> * var(--tint-strength))，颜色只走 var(--tint-rgb) / var(--tint-color) 这条链。没乘因子、或绕过链直接读 --window-tint-rgb， 都会被 static-check 5b 节拦下——否则「着色浓度」滑块拖着，你的界面却纹丝不动。

__surface 接口

接口说明
getLevel()当前等级（0-4）；存储值非法时回落 3
setLevel(0..4)写 appearance.blurLevel 设置项，返回布尔（越界被中枢钳制不拒绝）
levels()5 条 {value, label, unit}（label：关闭/极轻/轻柔/标准/浓重）
token(role)返回 "var(--surface-blur-N)" 字符串（role 钳 1-5，缺省 3）
apply(el, {role, blurPx, over})给「自己底色和全局不一样」的浮层登记局部表面（按它自己的底色算局部文字令牌），返回注销函数
apply(el, {over:"wallpaper"})声明「这块表面的背景就是墙纸」→ 文字色推导改走墙纸档（启动台 / 预览 / 锁屏类）
releaseAll()释放全部登记（面板销毁时用）
effectiveBase() / currentTextColor(scope)当前底色（含着色）/ 当前文字色（"panel" | "wallpaper" 两档），做预览与自检用

等级写入走设置中枢（广播 settings-changed），所以系统设置里改、代码里改，两边不会各说各话。

逃生舱（确实需要一个阶梯表达不了的模糊值）

.my-odd-surface { --surface-blur: 26px; }   /* 行尾必须带注释：/* 逃生舱：<理由> */ */

机器门禁（static-check「模糊必须走系统令牌」节）扫 blur(<数字>px) 字面量和「有 blur 但没引用 var(--surface-blur」， 覆盖 assets/stylesheets/**、mods/**、src/** 的 .css 与 .js（JS 里拼样式串写裸 px 一样会红）。 注意 blurPx（__surface.apply(el,{blurPx:26})）是 lint 盲区：源码里没有 blur( 文本—— 但代价一分没少：用户的等级设置对它照样无感。非必要不用。
