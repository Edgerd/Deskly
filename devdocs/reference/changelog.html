版本与更新

VERSION 的三处同步规则 + 最近两个版本的摘要。完整条目在仓库 docs/产品更新信息.md。

升版本步骤（三处必须同步）

  1. manifest.json：version 与 version_name（Chrome 只显示 version，name 只是给本地扩展 UI 的展示名）；
  2. src/javascripts/version.js：VERSION = "x.y.z"（冷加载与资源戳都取它）；
  3. index.html：全部 ?v= 串（当前 15 处）——升版本 = 整站资源缓存一次失效。

然后在 docs/产品更新信息.md 头部按既有格式补一条 （## 更新日期：YYYY-MM-DD | 版本号：X + AI 总结 + 新增/修复/影响范围）。
