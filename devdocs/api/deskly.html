window.Deskly（能力入口）

唯一受权限门禁的接口组。薄壳：每个方法委托给既有 owner，不重造能力。

三条硬约定

  1. 受管方法一律返回信封 {ok, value?, reason?, permission?}，永不抛错： const r = await Deskly.fs.read("data/a.md"); if (!r.ok) return r.reason;
  2. 调用前在 manifest.json 的 permissions 里声明；没声明 = 直接 ok:false（不弹窗）；
  3. fs 的路径默认相对你自己的 /AppData/<插件id>/，越不出这个目录（osfs.scope(id) 守边界）。

免权限的只有：apps.list / apps.info / bus.* / fs.home / fs.temp / meta.*（目录、事件与自省，不构成能力）。

权限账本（15 条，api-grants.js）

权限名说明敏感（首调弹确认）
apps:launch启动应用安装时一次授权后静默
default-apps:read查扩展名/协议当前由谁打开静默
default-apps:write改绑扩展名/协议（含 http:/https: 接管）敏感
widgets桌面小组件静默
dynamic-icons动态图标（dock/启动台/商店/访达同步刷新）静默
window-style:self改自己窗口样式静默
window-style:others改别人窗口样式（主题包）敏感 激活一次覆盖后续
theme:apply整套切换配色敏感
files:read / files:write读写文件；写到 AppData 之外逐次确认write 越沙箱 敏感
system-patch:dock / finderbar / desktop / wallpaper / menu给对应系统组件插入/替换内容（5 条）敏感

判据是「会不会影响别人 / 会不会丢数据」。读文件、启动应用、小组件、动态图标、自身样式属于 「装了就该能用」——安装时一次性授权，不再打扰（否则开机 13 个内置插件各弹一轮）。

Deskly.apps

await Deskly.apps.launch("office.word");              // appId 或显示名都行
const all = await Deskly.apps.list();                  // 免权限
await Deskly.apps.default.set(".md", "notepad");        // 键：扩展名带点 / 协议带冒号
await Deskly.apps.default.resolve("http:");             // 生效值 + 来源（user/system/manifest）
await Deskly.apps.default.reset(".md");

默认应用解析是三级回退：用户改绑 → 出厂默认（SYSTEM_DEFAULTS）→ 插件 apps[].formats 声明； 用户的手工改绑永远压过声明。

Deskly.fs

const dir = Deskly.fs.home();                 // {path, temp, config, data}（免权限）
await Deskly.fs.write("data/notes.md", "…");  // 自动补父目录，不必先 mkdir
const f = await Deskly.fs.read("data/notes.md"); // File 对象
await Deskly.fs.writeAt("/文档/导出.txt", "…"); // 越出沙箱：按敏感逐次确认
// 硬边界：指向 /AppData/别人 的路径无论有没有权限都拒绝

Deskly.bus

const off = Deskly.bus.on("default-apps-changed", (detail) => repaint(detail));
Deskly.bus.emit("my-topic", payload);   // 同步派发；形状 = 内核 broadcast（document + bubbles + detail）
// plugin-unload 里 off()

Deskly.meta

自省：meta.apps() / meta.permissions()（本插件已声明账目）/ meta.version() 等，全部免权限。
