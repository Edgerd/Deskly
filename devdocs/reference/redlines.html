代码层

红线为什么谁拦
MV3 CSP：禁 eval / new Function / 内联 on* 事件属性；菜单 cmd 字符串只认「键名 + 至多一个字符串实参」 MV3 扩展页默认 script-src 'self'浏览器（硬）+ ui/menuCommands.js 正则
import 说明符不带 ?v=（宿主 index.html 的 script/css 带 ?v=VERSION 是另一回事） 带/不带 = 两个模块，内核模块双求值、全局钩子互相覆盖deep-check / 人工
backdrop-filter 一律 var(--surface-blur-N)；磨砂文字一律 var(--surface-text*)；不手写 blur(px) 模糊等级由系统统一分配；裸 px 让用户设置静默失效static-check 第 5 节（含 JS 拼样式串）
墙纸着色必须 calc(<固有浓度> * var(--tint-strength))，颜色走 --tint-rgb 链 「着色浓度」滑块必须真的乘上static-check 5b 节
.window 与 backdrop-filter 元素上禁用 transform / filter / clip-path（淡入淡出用 opacity 实现） 新合成层让 backdrop-filter 采样断链 / 错位人工（规范）
窗口 z 只来自焦点栈（window-manager，2050-9000 段）；浮层 z 只走 Z 表 两处各管一段，裸 z-index 越界会压穿动态窗口层级体检 / 人工
运行时资源文件命名 ASCII SW 与 %-编码链路对非 ASCII 的处理边界static-check 资源节
界面里不出现 emoji（图标用 assets 里的 PNG/SVG 资源） 跨平台渲染不一致，且与 macOS 复刻目标冲突人工（规范）

文案与 i18n

红线做法
新增用户可见文案 = 四语键齐备内核文案：zh-CN / en / ja-JP / cat 四份 assets/locales/*.json 同时加； 插件自带文案走 registerMessagesAll（四语都写，cat = 中文+喵），不往内核语言包塞键
t(key, fallback) 键必须是字面量，且必带兜底动态拼键（t("a."+x)）会被 static-check 标记；用三目选两个字面量键
data-i18n 只认两个属性data-i18n + data-i18n-fallback；placeholder/title 变体没有内核代码读（见 i18n）

数据与存储

红线做法
设置读写只走 window.__settings别往 localStorage 手写第三个键；owner 读法决定落盘形态（on/off）
日志只走 window.__log（console.* 已被自动归档）来源显式写 plugin/<id>
OSFS 路径取 OSFS.TOP / OSFS.scope(id)不写 "/文档" 字面量；不造虚拟目录层
temp/ 不可依赖持久性读不到 = 缓存未命中，不当错误、不当数据库
NeedsReauthError 不静默回落按 err.name 判别；界面如实说「需要重新授权」，绝不写「已保存」
删除收口在 trash.jsUI 侧不直接 OSFS.remove（清倒走 emptyTrash）

资源与图标

红线做法
应用图标一律 PNG禁 SVG（程序坞/启动台/商店共用位图）；菜单栏单色 glyph 例外
图标先查 assets/icons/，找到复制进插件目录manifest 只写裸文件名；库原文件不移走；没有就不声明（自动落 GENERIC_APP_ICON 占位图）
manifest.permissions 必写（哪怕 []）没声明的能力调用直接 ok:false；取值只能来自 22 条 PERMISSION_NAMES
plugin-unload 必须释放全局注册监听 / 定时器 / window.__* 钩子 / __menuActions 键 / settings 订阅——模块表不回收旧实例
