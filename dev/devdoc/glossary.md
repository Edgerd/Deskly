# Deskly 界面术语表（对照 macOS 中文手册）

> 依据：苹果《iMac 入门指南》2024 年款（macOS Sequoia 15），本地镜像在
> `docs/iMac-2024-macOS15-知识库/`。本表是**界面用词**的唯一标准：
> 新增 UI 文案先查这里，`dev/static-check.mjs` 会按本表的禁用词扫描语言包与 `i18n.t` 兜底串。

## 三、内部标识的处理决定（2026-10-25）

- **DOM id / CSS 类**：新代码一律 `deskly-` 前缀；已有的 `#webstartos-brightness-overlay` 在本次
  F-20 中改名为 `#deskly-brightness-overlay`（纯内部，无兼容负担）。
- **localStorage 槽名**：仍保留 `webstartos_*` / `deskly-*` 混用现状，**不在本批次做全量改名**。
  理由：共 21 个键分散在设置中枢、Safari、照片、办公、访达等 owner 模块，改名必须同步迁移
  用户数据；收益只是内部整洁，风险却是「升级后设置丢失」。若后续要改，单独开一项迁移任务，
  要求「先备份、后改名、失败回滚」。
- **可见文案**：不允许出现旧品牌 `WebStartOS`。旧值 `WebStartOS-Home` 已在 F-20 移除，
  改为 i18n 文案。

## 四、守卫

`dev/static-check.mjs` 会扫描：

1. `assets/locales/zh-CN.json` 的所有字符串值；
2. `src/` 与 `mods/` 中 `i18n.t("key", "兜底文案")` 的兜底文案。

命中上表「禁用」列的词即报错（退出码 1）。注释里的历史用词不参与扫描——它们不面向用户。
