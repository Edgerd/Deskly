版本与更新

怎么升版本（三处必须同步）+ 最近几个版本的摘要。完整条目在仓库 docs/产品更新信息.md。

升版本步骤（三处必须同步，漏一处就是缓存灵异事件）

  1. src/javascripts/version.js：VERSION = "x.y.z"——冷加载的资源戳、「关于本机」里的版本行都取它；
  2. 扩展根 manifest.json：version 与 version_name（Chrome 只显示 version，version_name 是给本地扩展管理页的展示名）；
  3. 根 index.html：全部 ?v= 串（当前 15 处）——升版本 = 整站资源缓存一次性失效。

然后在 docs/产品更新信息.md 头部按既有格式补一条（# vX.Y.Z（日期） + 新增功能 / 优化改进 / 问题修复 / 破坏性变更 / 升级说明）。 版本号规则：正式发布按 0.01 步长递增；预发布（Alpha/Beta/RC）只递增预发布标识。

v0.4.3（2026-11-07）

  • 新增菜单栏台前调度状态项（可在「在菜单栏显示台前调度」关闭）；窗口总览新增「把窗口拖到屏幕上缘停留约 0.4 秒」打开方式；菜单栏「窗口」菜单列出当前全屏空间、点选即切换。
  • 台前调度支持把窗口拖到左侧缩略图并入该组，拖到空白处恢复按应用分组。
  • 未知类型文件双击弹出「打开方式」选择器（可勾选始终使用该应用）；文件拖到程序坞应用图标上，按能否打开给出高亮或轻提示。
  • 桌面支持撤销「新建」，也可在已选中图标上慢速二次单击进入重命名。
  • 优化：进出全屏 / 分屏时墙纸 320ms 内压暗 10%、退出自动还原；长按绿键 0.5 秒直接弹出窗口菜单。
  • 修复：台前调度左侧缩略图占位（开启时先在窗口可见时取图、收尾按应用补拍）、缩略图裁切压扁（按实际宽高比等比适配、停靠区整条滚动）、标题清晰度（12px / 600 字重 / 双层投影）；窗口打开瞬间先露出半成品、设置面板切换先空白一帧。

v0.4.2（2026-11-07）

  • 桌面改为「桌面目录」的文件视图；右键「新建」可建文件夹 / 文本 / Office 空白文档；新增「显示简介」（⌘I）与右键「压缩」标准 ZIP。
  • 图片库改为直接读取图片目录并支持挂载外部文件夹；快速查看独立为系统应用；应用快捷方式可放到桌面；内置应用统一走公开文件接口（越界拒绝并返回错误码）。
  • 修复：桌面图标双击无反应 / 拖动后视口被拽回；文件管理器空目录提示浮层常驻；选中图标后内容边距跳动；写入中断留半成品（改原子写）；列表与搜索暴露隐藏与临时文件。

v0.4.1（2026-11-06）

  • 全屏成为独立空间；新增分屏浏览、台前调度、窗口总览（⌃↑）与空间轮换（⌃← / ⌃→）；窗口菜单补齐移动与调整大小、填充与排列、全屏幕三组命令。
  • 窗口事件补齐为 open/close/focus/blur/resize/move/minimize/restore/fullscreen/zoom/tile/level-change 十二个；绿键单击全屏、按住 Option 缩放；红绿灯符号与悬停热区按 F0 规范对齐；系统动作注册表接入聚焦搜索、控制中心与设置开关。
