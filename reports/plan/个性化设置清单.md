# 个性化设置清单（现状盘点）

只读盘点，未改代码、未改设置、未提交 git。范围：`src/javascripts`、`mods/*` 的 manifest 与插件脚本、`mods/system-settings/panes/*`。行号为 2026-11-08 当前工作区。

口径：

- 键名照抄代码，包含 `hidden: true` 的键；业务数据、缓存、凭据另列，不计入设置键。
- 持久化统一写 `LS:槽名`；共享 JSON 槽写 `LS:槽名#jsonPath`；IndexedDB 写库/表。
- 「界面入口」写现有面板与分组；「无界面」表示代码没有可用控件。
- 系统设置中枢的默认槽名规则见 `src/javascripts/settings.js:78-80`：键名中的 `.` 换成 `-`，定义里有 `slot` 时以 `slot` 为准。

数量口径：**108 个系统设置键**（含 7 个 hidden；其中 5 个是 2026-11-08 追加的顶栏取色键）、**8 个插件内独立偏好键**、**14 组业务数据/运行态存储**（非设置）。

补充说明：

- 这 5 个键由 `src/javascripts/menubar-tint.js` 在启动时自注册（与 `surface.js` 同一模式），没有写进 `settings-definitions.js`。
- 默认值刻意取「与改造前视觉一致」：不透明度 `0`（不额外加底色）、模糊 `100`（沿用系统第 3 档）、文字颜色 `auto`（按壁纸顶部明暗算黑白）。录制中的宣传片素材不会因默认外观改变而前后不一致。
- 取色只消费壁纸配置里已有的 `thumb`（48 px JPEG），换壁纸或换壁纸类型由 `wallpaper-change` / `wallpaper-tint-change` 触发重算，结果按壁纸配置缓存。

## 13 异常

### 13.1 有键无界面

| 键 | 现状 | 判断 |
|---|---|---|
| `dock.order` | 只能拖拽程序坞图标排序，设置面板没有控件，也没有「恢复默认顺序」入口 | 代码支持、用户改不到；顺序本身可改，但键不可见 |
| `dock.recents` | 无控件；由程序坞自动维护 | 隐性键，用户无法清空/编辑 |
| `wallpaper.config` | `hidden:true`，但墙纸面板通过 `wallpaper.js` 直接写；没有通用控件 | 隐藏是渲染层约定，实际可用 |
| `calculator.mode` / `.rpn` / `.convert` / `.units` | 应用内按钮改变并记忆，设置面板不显示 | 设计上就是应用记忆，不宜当设置暴露 |
| `controlcenter.wifi` / `.bluetooth` / `.airdrop` / `.airplane` / `.mirroring` | 卡片存在，但 `unavailable:true`，点击无实际网络效果 | 有界面但不可用；属于「假设置」 |

### 13.3 重复或冲突

| 项 | 涉及键 / 文件 | 冲突表现 |
|---|---|---|
| 通知被两层闸门拦截 | `notify.enabled` + `controlcenter.focus`（`ui/notification.js:61/127`） | 两个开关都能让横幅不出现；用户关掉一个仍可能被另一个拦截，界面未说明主从 |
| 高亮颜色与强调色 | `appearance.accent` + `appearance.highlight`（默认 `accent`） | 默认跟随强调色；一旦显式选高亮色，两个键控制同一视觉结果且不再同步，界面没有「跟随强调色」与「自定义」的从属说明 |
| 两个「显示最近使用的应用」 | `dock.show.recent`（程序坞）与 `desktop.stage.showRecent`（台前调度） | 文案几乎相同，位置相邻（`panes/dock.js:415/437`），但作用对象不同，容易被当成同一个开关 |
| 台前调度开关两处 | `controlcenter.stage` | 控制中心卡片与桌面与程序坞 › 台前调度都渲染同一键，现有界面未标注主入口 |
| 调试开关两处 | `debug.captureConsole` / `debug.persist` | 开发者面板（`panes/debug.js`）与隐私面板（`panes/privacy.js:322/325`）同时出现，无主从标记 |
| 亮度 / 音量两处 | `display.brightness`、`sound.master`、`sound.muted` | 显示器/声音面板与控制中心快捷滑块共用键；值同步，但界面没有「此处为快捷副本」提示 |
| 废纸篓图标双写 | `trash.icon` + `trashIcon.js:36` | 设置中枢 apply 与模块直接写同一槽；值相同，幂等，但写入方有两个 |
| 计算器背景与系统毛玻璃 | `calculator.background` + `appearance.transparency` | `glass` 在系统关闭毛玻璃时被强制成实底；跨键副作用未在计算器设置里说明 |
| 语言键双写 | `general.language` 槽 `webstartos_language` + `i18n.js:33` | 同一槽两个入口；切换后一致，但绕过设置中枢时不会触发同一条 apply 链 |
| Siri 光球尺寸 | `siri.orb.size` 槽 `siri-orb-size` + 插件旧读法 | 插件同时读设置中枢与同名 localStorage 槽；值相同，属兼容路径，不是两套值 |

### 13.4 依赖关系（不是异常，但界面未表达）

- `appearance.tintStrength` / `tintHue` 依赖 `appearance.wallpaper.tint` 开启。
- `dock.zoom.amount` 依赖 `dock.zoom`。
- `display.nightShiftIntensity` 在 `display.nightShift` 与 `display.nightShiftAuto` 都关闭时不产生效果。
- `spotlight.files` 无文件夹授权时没有结果。
- `controlcenter.stageInMenuBar` 在 `controlcenter.stage` 关闭时没有可见对象。
- `lock.requirePassword` / `lock.lockAtBoot` 在未设置登录密码时不生效。

## 14 总体判断

个性化密度在**外观与桌面外围**偏高：108 个设置键里，外观、程序坞、菜单栏、墙纸、光标占了大半，且颜色、毛玻璃、着色、图标、滚动条都有独立旋钮；**窗口行为与桌面内容**明显偏空：没有窗口动画、吸附、分屏比例、桌面图标大小/排列、显示隐藏文件、系统字号、快捷键重映射的可配置键，台前调度也只有 4 个外围开关；插件偏好则散落在各应用内部，只有计算器、Siri、办公套件的少数项被系统设置收编。
