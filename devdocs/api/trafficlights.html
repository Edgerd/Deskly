窗口红绿灯（titlebar controls）

一个标签声明三颗灯。结构、符号、hover/禁用/非活跃状态机都封在 Shadow DOM 里，应用只声明位置形态与能力。

标准写法：放进标题栏

<div class="myapp window" data-window="size:900x620 centered">
  <header class="myapp-titlebar" data-titlebar>
    <deskly-traffic-lights class="wintools" placement="titlebar"></deskly-traffic-lights>
    <!-- 标题 / 工具栏按钮 -->
  </header>
  <section class="myapp-body">…</section>
</div>
  • 必须放在带 data-titlebar 的元素里：窗口拖拽只认它；没有标题栏元素的窗口才会退回「顶部灯区带」。
  • placement="titlebar"（缺省）表示内联形态：组件读取标题栏的 padding-left，把 margin-left 补齐到 --traffic-inset（20px）。 应用不要再写 margin-left: calc(var(--traffic-inset) - 12px) 这类补偿， 标题栏改内边距也不会把灯推歪。
  • 标题栏用 display:flex; align-items:center 时三颗灯自动垂直居中； 组件自身也带 align-self:center 兜底。
  • 标题栏不要加 transform / filter：会破坏窗口与侧栏的 backdrop-filter。

无标题栏：悬浮定位

<deskly-traffic-lights class="wintools" overlay></deskly-traffic-lights>

照片、记事本、Office 这类内容顶到窗口边缘的界面用 overlay （等价于 placement="overlay"）：绝对定位到 left: var(--traffic-inset); top: var(--traffic-top)，不占布局。

能力开关

<deskly-traffic-lights class="wintools" variant="dialog"></deskly-traffic-lights>  最小化 / 缩放禁用
<deskly-traffic-lights class="wintools" no-zoom></deskly-traffic-lights>            只禁用缩放
<deskly-traffic-lights class="wintools" no-minimize no-close></deskly-traffic-lights>

禁用规则只收紧、不放宽：variant="dialog" 与 manifest 的能力声明求交， 不会出现「清单说可最小化，于是对话框的禁用位又被点亮」的分叉。

JS API（src/javascripts/ui/trafficLights.js）

导出说明
attachTrafficLights(win, { anchor, placement, variant, noMinimize, noZoom }) 推荐入口。幂等：把灯插成 anchor 的第一个子节点；anchor 接受元素或选择器，缺省取窗口内第一个 [data-titlebar]。没有标题栏或显式 placement:"overlay" 时退回窗口根并悬浮定位。已有的 overlay 灯不会被误搬进标题栏。
createTrafficLights(opts)创建游离宿主（测试或自定义挂载时用）。
mountTrafficLights(win, opts)attachTrafficLights 的兼容别名； window-manager 在第三方窗口缺灯时自动调用。
getTrafficLights(win)取窗口自己的灯宿主（:scope 优先，避免命中嵌套窗口）。
setTrafficLightsEnabled(win, caps)按 {close,minimize,zoom} 收紧能力； 只能关、不能开。
setTrafficLightsActive(win, active)切换非活跃灰化，只改类名不触发布局。
TAG / ACTION_EVENTdeskly-traffic-lights 与 deskly:window-action。动作冒泡给 window-manager，组件不直接改窗口状态。

几何令牌：只覆盖令牌，不重写布局

令牌默认说明
--traffic-size12px圆点直径；符号尺寸由它推导
--traffic-gap8px三颗灯间距
--traffic-inset20px到窗口左缘的距离（内联形态由组件自动补齐）
--traffic-titlebar38px--traffic-top 由它推导；标题栏更高时在标题栏上覆盖它
--traffic-z10内容浮层压住灯时调高（照片预览用 210）
排查顺序 灯的位置不对 → 先确认它是不是标题栏的第一个子节点、标题栏有没有 data-titlebar；再看是否有应用样式覆盖了 margin-left。灯被内容盖住 → 查 --traffic-z 与浮层 z-index，不要反向压低内容层。
