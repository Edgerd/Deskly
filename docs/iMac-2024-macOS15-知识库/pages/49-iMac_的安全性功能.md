# iMac 的安全性功能

搭载 Apple 芯片的 iMac 提供以下安全性功能，可保护电脑上的内容以及防止在启动时载入未经授权的软件 App：

- *安全启动：*安全启动支持自动打开。旨在用于验证启动时电脑上载入的操作系统软件是否经过 Apple 授权。

  如果 iMac 因检测到不信任的组件而无法启动，它会从安全的恢复分区启动并自动修复可能的问题。若要了解如何设定安全选项，请参阅[在搭载 Apple 芯片的 Mac 上更改启动磁盘的安全性设置](https://support.apple.com/zh-cn/guide/mac-help/mchl768f7291)。

- *安全储存：*iMac 的储存驱动器通过硬件密钥进行加密，可提供高级别的安全性。一旦发生灾难性的故障，可能无法恢复数据，所以你需要将文件备份到外部来源。请参阅[在搭载 Apple 芯片的 Mac 上使用 macOS 恢复](https://support.apple.com/zh-cn/guide/mac-help/mchl82829c17)。

  你可以设置时间机器或其他备份方案来定期备份文件。请参阅[使用时间机器备份文件](https://support.apple.com/zh-cn/guide/mac-help/mh35860)和 Apple 支持文章：[使用时间机器备份你的 Mac](https://support.apple.com/104984)。

- *系统完整性：*iMac 中的 Apple 芯片设计用于验证启动时载入的 macOS 软件版本是否经过 Apple 授权，并在后台继续工作以保护为 macOS 建立的授权。这使得恶意软件或恶意网站更难利用你的 Mac。

- *数据保护：*除了 iMac 的默认储存驱动器加密之外，第三方 App 开发者还可以使用文件级别加密以更好地保护敏感数据，而不会影响系统性能。

*【注】*在少数情况下，如 macOS 升级期间电源故障，iMac 可能会没有反应；芯片上的固件可能需要修复。请参阅 Apple 支持文章：[如何修复或恢复 Mac 固件](https://support.apple.com/108900)。
