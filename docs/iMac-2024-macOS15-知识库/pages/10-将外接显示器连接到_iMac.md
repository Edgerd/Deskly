# 将外接显示器连接到 iMac

iMac 有两个或四个支持视频输出的 USB-C 端口。你可以将最多一台外接 6K 显示器、投影仪或 HDTV 连接到双端口机型的端口之一。四端口 iMac 可支持最多两台外接 6K 显示器。有关端口的更多信息，请参阅[浏览 iMac](https://support.apple.com/zh-cn/guide/imac/apd2e7352054/2024/mac/15)。

*【注】*如果将多台设备连接到一个端口且其中一台设备是外接显示器，则显示器必须是所连接设备中的最后一台设备。使用多端口转换器或集线器时不适用。

**【提示】**如果 Apple TV 连接了 HDTV，你可以使用隔空播放以最高 1080p HD 镜像 iMac 屏幕。请参阅[通过“隔空播放”在更大的屏幕上流播放内容](https://support.apple.com/zh-cn/guide/imac/apdf1417128d/2024/mac/15)以获取详细信息。

如果显示器的接口与想要使用的端口不匹配，你可以结合转换器（单独销售）使用。请访问 [apple.com/cn](https://apple.com/cn)、当地 Apple Store 商店或其他经销商以了解更多信息和可用性。请查阅显示器的文稿或咨询显示器的制造商以确保选取正确的产品。请参阅 Apple 支持文章：[适用于 Mac 上雷雳或 USB-C 端口的转换器](https://support.apple.com/102477)。

| 若要连接此设备 | 使用此连接线或转换器 |
| --- | --- |
| Apple Pro Display XDR | 雷雳 3 (USB-C) 连接线 |
| 雷雳 3 (USB-C) 显示器 | 雷雳 3 (USB-C) 连接线 |
| USB-C 显示器 | USB-C (USB 3.1) 连接线 |
| 雷雳 2 显示器 | 雷雳 3 (USB-C) 转雷雳 2 转换器 |
| HDMI 显示器或 HDTV | USB-C 转 HDMI 转换器或 USB-C 数字 AV 多端口转换器 |
| VGA 显示器或投影仪 | USB-C VGA 多端口转换器 |
| DisplayPort 或 Mini DisplayPort 显示器 | USB-C 转 DisplayPort 或 Mini DisplayPort 转换器 |
| DVI 显示器或投影仪 | USB-C 转 DVI 转换器 |

**调整和排列显示器。**连接外接显示器或投影仪后，请使用[系统设置](https://support.apple.com/zh-cn/guide/imac/aside/apd796e4d5da/2024/mac/15)中的“显示器”设置来设定如何排列显示器、打开或关闭屏幕镜像以及对颜色、分辨率等进行其他调整。请参阅[将显示器连接到 Mac](https://support.apple.com/zh-cn/guide/mac-help/mchl7c7ebe08)。

**故障排除。**如果不确定你的 iMac 支持连接几台外接显示器，请查看“技术规格”。打开“系统设置”，选取“帮助”>“iMac 技术规格”，然后找到“视频支持”（可能需要滚动）。若要排除外接显示器的问题，请参阅[如果外接显示器处于黑屏状态或者分辨率较低](https://support.apple.com/102501)。
