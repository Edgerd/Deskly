# 给无线配件的电池充电

妙控键盘、妙控鼠标和妙控板配备内建的可充电电池。

**检查电池电量。**点按菜单栏中的

![“控制中心”状态菜单](../images/IL_ControlCenter.png)

*图：“控制中心”状态菜单*

，将指针移到蓝牙项目上，然后点按其旁边的箭头。

**给电池充电。**使用 USB-C 充电线将妙控键盘、妙控鼠标或妙控板连接到你的 Mac。

**【提示】**若要更快地充电，请确保在连接到 iMac 时，你的输入设备已开启。

**进一步了解。**请参阅[处理和回收信息](https://support.apple.com/zh-cn/guide/imac/apd91eb694f4/2024/mac/15)或访问 [Apple 锂离子电池](https://www.apple.com/cn/batteries/)。
