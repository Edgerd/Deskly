# 产品更新信息

> 本文件是 `docs/changelog.json` 的可读版本，二者由 `node dev/changelog-check.mjs` 校验保持一致，界面读取 JSON。
> 各内置应用自己的更新历史见 `mods/<应用>/changelog.json`；0.3.0 之前的内部版本存档见《产品更新信息-旧版.md》。

## v0.4.3（2026-11-07）

### 新增

- 菜单栏台前调度状态项：开启台前调度后出现在状态区，点击打开控制中心，可在「在菜单栏显示台前调度」中关闭。
- 窗口总览新增打开方式：把窗口拖到屏幕上缘并停留约 0.4 秒。
- 菜单栏「窗口」菜单列出当前全屏空间，点选即切换。
- 台前调度支持把窗口拖到左侧缩略图上并入该组，拖到空白处恢复按应用分组。
- 双击未知类型的文件时弹出「打开方式」选择器：列出可打开该类型的应用，可勾选「始终用此应用打开」，不再退回快速查看。
- 把文件拖到程序坞的应用图标上：目标应用能打开该类型即高亮、松手打开；不能打开时给出一次轻提示，不再静默失败。
- 桌面支持撤销「新建」：新建空文件夹或空文件后按 ⌘Z 可移除该项目并回收其图标位置。
- 桌面支持慢速二次单击重命名：在已选中图标上再单击一次（间隔可配置，默认 500 毫秒）即进入重命名，与双击打开不冲突。

### 优化

- 进出全屏/分屏时墙纸在 320 毫秒内压暗 10%，退出后自动还原。
- 长按绿键 0.5 秒直接弹出窗口菜单，松手不会误触发全屏。

### 修复

- 修复台前调度左侧缩略图显示为占位图的问题：开启时先在窗口仍可见的状态下取图，之后在焦点、移动、缩放、平铺收尾时按应用补拍。
- 修复缩略图被裁切或压扁的问题：按窗口实际宽高比等比适配，画面完整显示，超出停靠区改为整条滚动。
- 优化缩略图标题清晰度：字号 12px、字重 600，双层投影保证深浅壁纸下都可读。
- 修复应用窗口打开瞬间先露出半成品的问题：窗口在插件样式表与首屏布局就绪前不参与绘制，冷加载时不再先显示「没有毛玻璃、元素错位」的一帧；开窗兜底等待放宽到 1.2 秒，宁可整体晚出现也不显示中间态。
- 修复设置面板切换时先空白一帧的问题：旧面板画面保留到新面板构建完成，清空与替换在同一个同步任务内完成；首次打开也等默认面板装配完成后再显示窗口。

## v0.4.2（2026-11-07）

### 新增

- 桌面改为「桌面目录」的文件视图：选中、双击打开、拖拽、右键菜单、新建、删除、撤销与文件管理器共用同一套文件系统接口，其它程序写入的文件会即时出现。
- 桌面右键新增「新建」子菜单：可新建文件夹、文本文件与 Word / Excel / PowerPoint 空白文档，创建后立即进入重命名。
- 新增「显示简介」（⌘I）：桌面与文件管理器共用同一个信息面板，显示种类、大小、所在位置、修改日期与文件夹内的项目数。
- 右键「压缩」只生成标准 ZIP（存储模式，不引入压缩算法）。
- 图片库改为直接读取图片目录：启动自动扫描、支持添加与删除，并可挂载外部图片文件夹（只读或读写，越界访问一律拒绝）。
- 快速查看独立为系统应用：全局单例、后打开者接管，办公文档由注册的预览器渲染。
- 应用快捷方式可以放到桌面：快捷方式就是普通文件，可重命名、移动或删除。
- 内置应用统一走公开文件接口：读写文件需先授权，越界自动拒绝并返回可编程错误码。

### 修复

- 修复桌面图标双击无反应、视口被拽回左上角的问题：拖动改为越过阈值才移动节点，纯点击不再触发整盘重排。
- 修复文件管理器空目录提示浮层常驻并遮挡已渲染条目的问题。
- 修复桌面与文件管理器选中图标后内容上下边距跳动的问题：选中胶囊改为不占布局的外扩描边。
- 修复写入中断留下半成品文件的问题：改为原子写（暂存后提交，失败回滚）。
- 修复列表与搜索暴露系统隐藏文件与临时文件的问题。

## v0.4.1（2026-11-06）

### 新增

- 全屏成为独立空间：进入全屏后其他窗口留在原空间，切回普通空间时窗口位置与层级自动恢复；Esc 或 ⌃⌘F 退出。
- 新增分屏浏览：窗口菜单可将窗口放到屏幕左侧或右侧，中间分隔条拖动调整占比并记住上次比例，可选取另一窗口拼接。
- 新增台前调度：当前应用窗口居中，其他应用在左侧停靠为缩略图，点击切换，窗口按应用自动分组。
- 新增窗口总览（⌃↑）与空间轮换（⌃← / ⌃→）。
- 窗口菜单新增移动与调整大小、填充与排列、全屏幕三组命令，支持按住 Option 展开多窗排列。
- 窗口事件补齐为 open/close/focus/blur/resize/move/minimize/restore/fullscreen/zoom/tile/level-change 十二个。

### 优化

- 绿键单击进入全屏、按住 Option 缩放；分屏中使用绿键菜单退出分屏。
- 红绿灯符号与悬停反馈按 F0 规范对齐，标题栏按钮热区与按钮语义修正。
- 系统动作注册表：聚焦搜索可检索「切换台前调度」等窗口动作，控制中心卡片、设置开关与可搜动作共用同一个状态源。

## v0.4.0（2026-11-05）

### 新增

- 晃动查找指针新增回弹动画：先过冲再回落、保持片刻、平滑收回，并遵循「减少动态效果」设置。

### 优化

- 开启「允许墙纸为窗口着色」后，所有窗口的标题栏文字、标签、输入框文字与图标统一切换为可读色，输入控件改为深色半透明底。
- 输入框聚焦样式收敛：搜索框、文本与密码输入、下拉框聚焦时保留原有底色，只加描边与外环，不再变成实心白底。
- 文件选择按钮与原生下拉框统一为自定义控件样式，覆盖悬停、按下、禁用与聚焦状态。
- 墙纸持久化重构：上传图片与网络墙纸改存浏览器本地数据库，离线或接口失败也能显示；启动时先铺同图低清版再换全尺寸，不再先闪默认墙纸；旧墙纸自动迁移，释放本地存储配额。

### 修复

- 修复上传大图后刷新墙纸丢失的问题。
- 修复网络墙纸刷新或断网后无法显示的问题。
- 修复锁屏期间全局快捷键仍可生效的问题：锁定状态下除密码输入必需的按键外全部拦截，解锁后立即恢复。
- 修复第三方插件可通过伪造系统事件给自己偷开权限、或清空他人授权记录与默认应用设置的问题。
- 修复第三方插件可冒用他人身份进行文件操作、使操作记到他人账上的问题。
- 修复外接磁盘文件夹作为存储位置时，第三方插件可用大小写或拼写变体路径读写他人应用数据的问题。
