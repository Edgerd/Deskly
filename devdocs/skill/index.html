插件开发技能包（喂给 AI）

这是一个面向 AI 编码助手的技能包（skill）：把目录整体喂给 AI，它就能按本仓库规范从零做出一个 Deskly 插件。人类读者把这页当导览即可。

包里有什么

skill/plugin-dev/
├── SKILL.md                  # 技能主文件（带 name/description frontmatter，AI 入口）
├── checklist.md              # 交付前自检清单（逐条可判否）
└── templates/                # 可直接复用的骨架（改 id 与文案即可）
    ├── manifest.json
    ├── index.html
    ├── style.css
    └── script.js

怎么用

  1. 把 skill/plugin-dev/SKILL.md 的内容发给 AI（或把目录放进它的技能加载路径）；
  2. 告诉它你的插件要做什么（名称、界面、需要的系统能力）；
  3. 它会按规范产出 mods/<id>/ 四个文件 + 图标声明，并自检交付清单；
  4. 你拿到产物后跑 node dev/static-check.mjs 复核（参见开发自检工具）。

技能包覆盖的规范要点

  • 真实运行模型（注入宿主文档、无 iframe 沙箱）与权限账本边界；
  • manifest 全字段、图标 PNG 硬规则、路径三种写法；
  • 冷加载两条铁律（入口重跑、全局资源必须在 plugin-unload 释放）；
  • 主题（html[data-theme] 浅色/深色/自动）与四语 i18n（zh-CN / en / ja-JP / cat）；
  • macOS Sequoia 复刻样式规范：模糊令牌、cubic-bezier(0.16, 1, 0.3, 1) 缓动、禁 emoji、尊重减少动态效果；
  • 宿主 API 清单（Deskly / __settings / __log / __dialog / __notify / __popover / paths.js）与 22 条权限名；
  • 安装与打包流程（static-check → package-plugin → ZIP 三级安装链）。
