window.Deskly（能力入口）

插件申请系统能力的统一入口。它是一层薄壳：每个方法都委托给内核里已有的 owner 模块（文件→OSFS、应用→plugin-manager、事件→document），不重新造一份。本页所有方法签名以 src/javascripts/os-api.js 为准。

三条硬约定

  1. 受管方法一律返回信封 {ok, value?, reason?, permission?}，永不抛错： 
    const r = await Deskly.fs.read("data/a.md");
if (!r.ok) { console.warn(r.reason); return; }
const file = r.value;
    被拒绝时是 ok:false 带中文原因，不是崩、也不是静默拿到 undefined 继续跑。
  2. 用之前先在 manifest.json 的 permissions 里声明。没声明 = 直接 ok:false（连弹窗都没有）。
  3. fs 的相对路径默认锁在你自己的 /AppData/<插件id>/ 沙箱里，越不出去（OSFS.scope 守边界）。

免权限的方法（目录、事件与自省，不构成能力，随便调）： apps.list、apps.info、bus.*、fs.home、fs.temp、windows.state、meta.*。

权限账本（22 条权限名，以 api-grants.js 的 PERMISSION_NAMES 为准）

两层机制：安装时用户确认一次清单（grantAll 记账）；运行时敏感权限第一次调用再弹一次「拒绝 / 仅此一次 / 始终允许」（弹窗实现见系统弹窗 dialog）。 账本存在 IndexedDB（库 webstartos-grants），跨会话生效；覆盖安装不会清账。

权限名说明敏感（首调弹确认）
apps:launch启动其它应用否
default-apps:read查询扩展名/协议当前由谁打开否
default-apps:write改绑扩展名/协议（含 http:/https: 接管）敏感
widgets桌面小组件（接口未落地，见文末）否
dynamic-icons动态图标（接口未落地）否
window-style:self改自己窗口样式（接口未落地）否
window-style:others改别人窗口样式（主题包类能力）敏感
theme:apply整套切换界面配色敏感
files:read读文件（自己的 AppData）否
files:write文件存储（本应用数据目录内）敏感
system-patch:dock / :finderbar / :desktop / :wallpaper / :menu给对应系统组件插入/替换内容（接口未落地）敏感（整个前缀都算）
window:read-others读取其他应用窗口的状态与事件否
window:manage-others改动、关闭或置顶其他应用的窗口敏感
window:chrome隐藏整组窗口控件或关闭按钮敏感
window:level把自己的窗口提升到浮动层或面板层否
quicklook:register为自己支持的文件格式提供快速查看预览否
menus:register在桌面与访达的文件右键菜单中增加条目否
shortcuts:write在桌面创建或移除应用的快捷方式否

敏感的判据是「会不会影响别人 / 会不会丢数据」。读文件、启动应用这类「装了就该能用」的，安装时一次授权后静默通行—— 否则开机每个内置插件都会各弹一轮，用户只会一路点拒绝。

Deskly.apps（启动与默认应用）

await Deskly.apps.launch("office.word");      // 需 apps:launch；appId、插件 id、显示名都行
const all = Deskly.apps.list();                // 免权限：全部可启动应用摘要 [{appId, pluginId, name, displayName, entry}]
const rec = Deskly.apps.info("文稿");          // 免权限：单个应用完整记录，查不到返回 null

await Deskly.apps.default.set(".md", "notepad");   // 需 default-apps:write；键 = 扩展名带点 / 协议带冒号
await Deskly.apps.default.get(".md");              // 需 read：当前由谁打开
await Deskly.apps.default.resolve(".md");          // 需 read：生效值 + 来源（user / system / manifest）
await Deskly.apps.default.reset(".md");            // 需 write：恢复系统默认

默认应用是三级回退：用户手工改绑 → 出厂默认（SYSTEM_DEFAULTS，23 条）→ 插件自我声明（单应用插件写根级 formats，多应用套件写 apps[].formats）。用户的改绑永远压过声明。

Deskly.fs（文件，默认锁在自己的沙箱）

const dir = Deskly.fs.home();                       // 免权限：{path, temp, config, data} 四个绝对路径
await Deskly.fs.write("data/notes.md", "…");        // 需 files:write；自动补父目录，不必先 mkdir
const r = await Deskly.fs.read("data/notes.md");    // 需 files:read；r.value 是 File 对象
await Deskly.fs.list("data");                        // 需 files:read
await Deskly.fs.remove("data/old.md");               // 需 files:write
const ok = await Deskly.fs.exists("data/notes.md");  // 需 files:read
const st = await Deskly.fs.stat("data/notes.md");    // 需 files:read；大小 / 修改时间 / 类型
await Deskly.fs.rename("data/a.md", "data/b.md");    // 需 files:write；同沙箱内移动
await Deskly.fs.copy("data/a.md", "data/backup/a.md"); // 需 files:write；目标写完整路径
const tmp = Deskly.fs.temp("cache.json");            // 免权限：临时目录路径（关窗即可丢的东西放这）
await Deskly.fs.writeAt("/文档/导出.txt", "…");      // 需 files:write；写沙箱外的公开路径

一条不给弹窗机会的硬边界：指向 /AppData/<别人的id>/ 的路径，无论有没有权限都拒绝——跨插件读别人的私有数据永远不行。

Deskly.bus（事件总线）

const off = Deskly.bus.on("default-apps-changed", (detail) => repaint(detail));
Deskly.bus.emit("my-topic", payload);       // 免权限；document 派发、bubbles:true
off();                                       // ★ plugin-unload 里必须退订
// "system:" 前缀的 topic 改在 window 上收发，与内核的 window 级事件（如 dock-size-change）对齐

形状与内核 app-registry.broadcast() 完全一致，所以内核那批广播（settings-changed / plugin-unload / default-apps-changed…）在这里都收得到。完整事件地图见事件与全局接口。

Deskly.windows（声明自己窗口的尺寸）

await Deskly.windows.configure(null, { width: 500, height: 640, resizable: false });
// target：窗口元素 / 窗口 id / null（= 自己的窗口）。只能配自己的窗口（按 data-plugin-id 校验），配别人的直接 ok:false
const st = Deskly.windows.state(el);   // 免权限：读框架 / 缩放态 / 全屏态

静态尺寸写在 HTML 的 data-window 里，运行期才知道的尺寸（比如按文档内容定初始大小）用这个接口改。字段与 data-window 同一套。

Deskly.ui.dialog（系统弹窗，免权限）

确认、提示、错误、输入、多选与进度都从这里出窗，权限框不在此列（只能由内核在敏感能力首次调用时发起）。

const ok = await Deskly.ui.dialog.confirm({ title: "要删除「草稿.md」吗？", message: "删除后无法撤销。", danger: true });
const name = await Deskly.ui.dialog.prompt({ title: "新建文件夹", message: "名称", value: "未命名文件夹" }); // 取消返回 null
await Deskly.ui.dialog.alert({ title: "已完成", message: "文件已导出。" });

取消值、焦点规则、进度控制器与迁移写法见系统弹窗 dialog。

Deskly.meta（自省，全部免权限）

成员说明
meta.version当前系统版本号（属性，不是函数，如 "0.4.3"）
meta.language() / meta.languages()当前语言代号 / 支持语言表 [{code, label}]
meta.onLanguageChange(fn)订阅语言切换，返回退订函数（plugin-unload 里调用）
meta.appName(nameOrId)把 appId / 插件 id / 中文原名翻成当前语言显示名
meta.permissions()22 条权限名全表 + 中文描述 + 是否敏感
meta.grants() / meta.grantedIds()自己的授权账本（只查自己，跨插件查询一律不给）
meta.can(permission)某权限现在能不能直接调（只查账，不弹窗、不改状态）
meta.caller()调试用：当前识别出的调用者插件 id（null = 认不出）
