# 妙控板

你可以通过简单的触控板手势在 iMac 上执行许多操作，如滚动浏览网页、放大文稿、旋转照片等。有了力度触控板，交互体验将借助压力感应功能又上升一个层次。触控板可提供反馈：当拖移或转动对象时，你将在对象对齐时感觉到轻微的振动，从而允许你进行更精确的处理。有关用力点按选项的示例，请参阅 Apple 支持文章：[如何使用力度触控板](https://support.apple.com/102309)。

若要将妙控板连接到 iMac，请参阅[将配件连接到 iMac](https://support.apple.com/zh-cn/guide/imac/apd376797067/2024/mac/15)。

以下是一些可在妙控板上使用的常用手势。

| 手势 | 操作 |
| --- | --- |
| ![点按手势符号。](../images/L0010_Click.png) *图：点按手势符号。* | **点按：**按下触控板的任意位置。或在“触控板”设置中启用“轻点来点按”，然后轻点即可。 |
| ![用力点按手势符号。](../images/L0009_PressFirmly.png) *图：用力点按手势符号。* | **用力点按：**点按，然后用力按下。你可以用力点按来查看更多信息，如点按文字来查看其定义，或点按地址来查看可在“地图”中打开的预览。 |
| ![辅助点按或右键点按手势符号。](../images/L0011_SecondClick.png) *图：辅助点按或右键点按手势符号。* | **辅助点按（即右键点按）：**双指点按来打开快捷键菜单。如果“轻点来点按”已启用，请用双指轻点或点按。或者在点按触控板时按下键盘上的 Control 键。 |
| ![双指滚动手势符号。](../images/L0012_TwoFingerScroll.png) *图：双指滚动手势符号。* | **双指滚动：**双指上下滑动来滚动。 |
| ![张开或捏合来缩放手势符号。](../images/L0013_PinchZoom.png) *图：张开或捏合来缩放手势符号。* | **张开或捏合来缩放：**张开或捏合大拇指与食指可放大或缩小照片和网页。 |
| ![轻扫以浏览手势符号。](../images/L0014_Swipe.png) *图：轻扫以浏览手势符号。* | **轻扫以浏览：**使用双指左右轻扫来浏览网页、文稿等内容，如同在书中翻页。 |
| ![打开启动台手势符号。](../images/L0015_LaunchPad.png) *图：打开启动台手势符号。* | **打开启动台：**快速打开[启动台](https://support.apple.com/zh-cn/guide/imac/aside/apd2d2a58738/2024/mac/15)中的 App。使用四指或五指捏合，然后点按一个 App 来打开它。 |
| ![在 App 之间轻扫手势符号。](../images/L0017_SwitchScreens.png) *图：在 App 之间轻扫手势符号。* | **在 App 之间轻扫：**若要从一个全屏幕 App 切换到另一个全屏幕 App，请用三指或四指左右轻扫。 |

**自定义你的手势。**在[系统设置](https://support.apple.com/zh-cn/guide/imac/aside/apd796e4d5da/2024/mac/15)中，点按“触控板”。在“触控板”设置中，你可以：

- 进一步了解每个手势
- 设定你想要使用的点按力度
- 决定是否使用压力感应功能
- 自定义其他触控板手势

**【提示】**如果自己会不小心误触发用力点按，请尝试在“触控板”设置中将点按力度调整至更强的设置。或者点按“查询与数据检测器”旁边的弹出式菜单并选取“三指轻点”。
