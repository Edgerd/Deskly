z-index 层级表（Z）

全站唯一的 z-index 来源：src/javascripts/zindex.js。浮层只走 Z 表，窗口只走焦点栈。下表与该文件逐条对齐。

两条铁律

  1. 浮层类元素（菜单栏、Dock、通知、弹层、启动台、警示背板……）只取 Z 表键值， CSS 里不出现裸 z-index 字面量（窗口内部的局部堆叠除外，且必须注释说明）。
  2. 窗口的 z 只来自 window-manager 焦点栈（2050-9000 动态段，到顶重排回收）：任何地方不手写 style.zIndex 定窗口层。手写 z-index 与焦点栈是两套账，窗口一动就会互相压穿。

改层级的正确姿势

  1. 改 zindex.js 一处（加键或改值，带上注释说明「为什么是这个高度」）；
  2. 消费方 CSS 里的值写死、注释指向 Z 键（站内现状：CSS 与 JS 两份值，注释是同步线索——改值时两边一起改）；
  3. 跑「层级体检」（顶栏调试菜单）核对没有裸值漏网。
