## 6. 项目架构与模块风险总览

```
index.html ─┬─ wallpaper-boot.js（同步首帧壁纸）
            ├─ main.js → log.js（接管 console）→ notification
            ├─ plugin-manager.js（插件发现/冷加载/多应用外壳/预取）
            ├─ finderbar.js / dock.js / desktop.js / window.js（UI 骨架）
            └─ bootstrap.js（设置 schema → 外观 → 表面 → 壁纸 → … → SW 注册）
sw.js（MV3 background + 页面 register 双通道，IndexedDB 插件资源服务）
mods/*（13 内置插件，manifest 声明权限；office 为多应用插件 word/excel/ppt）
```

风险热区（按复杂度 × 影响面）：

1. `dock.js`（2,233 行）+ `dock/drag.js` — 启动期必经路径，差量重绘已做，仍是最大单文件。
2. `window-manager.js` + `wm/genie-*` — Genie 动画有 GPU 降级/冷却/收场兜底，历史缺陷密集区。
3. `plugin-manager.js` + `sw.js` + `api-grants.js` — ZIP 插件安装/持久化链路，跨页面-SW-IndexedDB 三方时序。
4. `osfs.js`（1,050 行）— File System Access API 授权与虚拟文件系统。
5. `mods/photos/script.js`（134 KB 单文件）、`mods/office/view-*.js`（正在重写）— 插件侧最大维护风险。
