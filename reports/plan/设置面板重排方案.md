# 设置面板重排方案

只读方案，未改代码、未改设置、未提交 git。范围：`mods/system-settings` 的左侧分区、面板内条目顺序、右侧控件与文案。设置键与现状见 [个性化设置清单](./个性化设置清单.md)。

本轮不新增、不删除任何设置键，只重排入口与控件，合并或复制现有键。登录密码、通知权限、文件授权仍按现有能力处理，不扩功能。

---

## 1 左侧分区

按用户找东西的顺序排，不按实现模块排。分区由上到下：先改看得见的外观，再改输入方式，再改声音提醒，再处理系统级条目，最后是安全与高级。

| 顺序 | 分区 | 定位 | 不放什么 |
|---|---|---|---|
| 1 | **外观与桌面** | 墙纸、深浅色、Dock、显示器、菜单栏。用户想「把桌面换个样子」时的全部入口 | 不放语言、通知、密码 |
| 2 | **输入与语音** | 键盘、鼠标、光标、Siri。按操作方式归类 | 不放窗口管理 |
| 3 | **声音与提醒** | 通知、音量、专注模式。三类都在处理「什么时候出声、什么时候静音」 | 不放显示器亮度 |
| 4 | **通用与系统** | 语言与时间、存储、备份、聚焦搜索、默认打开方式、新功能。低频但系统级 | 不放外观 |
| 5 | **安全** | 锁定屏幕、登录密码、隐私与授权。都涉及「谁能进来、数据给谁」 | 不放开发者选项 |
| 6 | **高级** | App 设置、开发者与日志。出问题时才进来 | 不放日常开关 |

分区顺序理由：

- 外观与桌面放第一，因为这里是用户最常改、也最需要即时反馈的一组；视觉结果就在右侧预览里。
- 输入与语音紧随其后，键盘、鼠标、Siri 都是「手和口怎么操作」，放在一起减少跨区查找。
- 声音与提醒独立成区，避免把音量塞进「外观」、把专注模式塞进「安全」。
- 通用与系统收低频但影响面大的项。语言放这里，因为切换后整个界面都会变。
- 安全单独成区，锁定屏幕与密码合并，隐私授权放在同一层。
- 高级放最后，App 设置和日志都属于「平时不看，出问题才看」。

去掉未实现的分区：账户、用户与群组、iCloud、屏幕使用时间当前没有可用面板，不占左栏位置。

### 新左栏结构

```
外观与桌面     外观 / 墙纸 / 桌面与程序坞 / 显示器 / 控制中心
输入与语音     键盘 / 鼠标 / Siri
声音与提醒     通知 / 声音 / 专注模式
通用与系统     通用 / 聚焦 / 默认应用
安全           锁定屏幕 / 隐私与安全性
高级           App / 开发者
```

18 个面板，6 个分区。面板数与现状接近，但分区从 7 个压到 6 个，且每区内部按用户任务聚拢。

## 2 面板内条目顺序

统一排序逻辑：

1. **先放「是什么」**：当前状态、主开关、主选择。
2. **再放「怎么调」**：从属滑块、颜色、位置、效果。
3. **最后放「高级或危险」**：恢复默认、清除、导出、诊断。
4. 一眼能看懂的项不写常驻说明，也不写悬停描述；有副作用、跨区域影响、和另一条冲突的项才写悬停描述。
5. 同一效果出现在两处时，主入口在前，快捷副本在后，并标「快捷副本」。

下面每个面板按最终顺序列出。控件列写最终控件；悬停描述列只出现在需要解释的条目，`—` 表示不写，理由见第 7 节覆盖表。

## 3 控件对齐

规则：

- 布尔 → 开关。
- 2–4 个短选项 → 分段控件，不用下拉，不用单选圆点。
- 5 个以上选项或名称较长 → 下拉。
- 有预览的选项 → 卡片或色块，不用下拉。
- 连续数值 → 滑块，右侧显示当前值和单位。
- 状态、只读信息 → 状态行，不放开关。
- 动作、危险操作 → 按钮行；危险操作单独成组。
- 同一语义在多个面板出现 → 同一控件、同一文案、同一键，并标主从。

需要改的现有控件：

| 项 | 现状 | 改为 | 理由 |
|---|---|---|---|
| 边栏图标大小 | 下拉 | 分段（小 / 中 / 大） | 只有三档，下拉多一次点击 |
| 显示滚动条 | 单选圆点 | 分段（自动 / 滚动时 / 始终） | 与位置、时间格式等短选项统一 |
| 计算器背景 | 下拉 | 分段（玻璃 / 实底） | 只有两项 |
| 控制中心不可用卡片 | 开关 | 状态行 + 「不可用」标记 | 开关点了不产生效果，容易误以为已控制 |
| 数值滑块 | 部分无单位 | 一律在右侧显示值和单位 | 亮度、音量、毫秒、像素需要直接读出 |
| 重复入口 | 无标记 | 行尾加「快捷副本」；主入口加「主入口」 | 防止用户以为两处是两个不同的值 |

保持不变：

- 外观模式用预览卡，因为需要看到深浅结果。
- 强调色用色块，因为颜色本身是结果。
- 高亮颜色用下拉，因为选项含「跟随强调色」且名称较长。
- 废纸篓图标用图片卡，因为需要看到图案。
- 台前调度位置、最小化效果、时间格式用分段。
- 通知停留时长、自动锁定、缓冲条数用滑块，因为这些是连续数值。

## 4 悬停描述与行高

### 4.1 交互

- 去掉每一项下面的常驻灰色说明。条目只留标题和控件。
- 指针进入整行后 **500 ms** 显示；快速扫过不触发。离开 **80 ms** 后收起。渐入 **120 ms**，渐出 **80 ms**；系统开启「减少动态效果」时改为直接显示/隐藏。
- 同一时刻只允许一个浮层。移到新行时先取消旧计时器，再换文案；不做堆叠。
- 浮层放在条目标题上方，与标题左对齐，宽度最多 300 px（中文）/ 340 px（英文），距面板左右各留 12 px。行在上半屏时放下方，下半屏时放上方；不得覆盖本行的控件区域，不得越出面板边界。
- 键盘聚焦到行或行内控件后 **350 ms** 显示同一段描述；`Esc` 收起；失焦收起；滚动时立即收起。
- 每个可聚焦行加 `aria-describedby` 指向浮层；浮层用 `role="tooltip"`；不打断读屏当前朗读。
- 触屏没有悬停：长按 **600 ms** 显示，松手收起；不新增常驻「i」图标。

### 4.2 行高与间距

- 普通行（开关、下拉、分段、按钮）：最小高度 **44 px**，上下内边距 10 px，左右 14 px。
- 滑块行：高度 **56 px**，标题与数值同一行，滑块独占下一行。
- 表格行：**40 px**；表头 32 px。
- 分组标题：上间距 **22 px**，下间距 **6 px**，字号 13 px，字重 600。
- 分组之间用 1 px 分隔线，不再插入空白占位行。
- 行内标题与控件垂直居中；控件最大宽度 240 px，滑块 260 px。
- 去掉常驻说明后，原本给说明预留的第二行高度一并收回；不允许出现「标题一行、空白一行、控件一行」的三段式。

## 6 文案规范与多语言

### 6.1 写法

- 标题为名词或短动词短语，4–6 个字优先：`外观`、`程序坞`、`菜单栏`、`自动隐藏程序坞`。
- 悬停描述一到两句，只讲「改了什么、改完会怎样」；不解释好处，不推销。
- 用「你」或省略主语，不用「您」。
- 允许不完整句；`关闭后`、`只在……时生效` 可以单独成句。
- 数字和单位直接写：`32–128 px`、`0–100%`、`5500 ms`。
- 不用「让……更……」「轻松」「智能」「一键」「极致」「全新」「无缝」「一站式」「解锁」「颠覆」「引领」「生态闭环」。
- 不用感叹号；不用「不仅……而且……」「不是 A 而是 B」；不用堆叠形容词。
- 不用「点击此处」；写「点按」或直接写动作。

### 6.2 语言包

四套语言包位于 `assets/locales/`：`zh-CN.json`、`en.json`、`ja-JP.json`、`cat.json`。

- `zh-CN` 与 `en`：本方案给出全部标题与悬停描述，可直接落库。
- `ja-JP`：本轮不填。先由日语母语者按 `zh-CN` 语义重写，保留 `Dock`、`Siri`、`Bing` 等产品名，不机翻。
- `cat`：本轮不填。沿用项目现有加泰罗尼亚语用词；没有对应词时保留英文原词，由熟悉该语言的人复核，不机翻。
- 补齐顺序：先补齐 `ja-JP` 的 102 个新键，再补 `cat`；两套都完成后跑键覆盖率检查，四套键数必须相等。

## 9 与现状的差异

### 9.1 左侧分区

- 旧：账户 / 通用 / 个性化 / 提醒 / 安全 / 输入 / 高级。
- 新：外观与桌面 / 输入与语音 / 声音与提醒 / 通用与系统 / 安全 / 高级。
- 账户、用户与群组、iCloud、屏幕使用时间没有实现，不占位置。
- 墙纸、外观、显示器、桌面与程序坞从「个性化」移到「外观与桌面」；控制中心从「通用」移到同一区。
- Siri 从「个性化」移到「输入与语音」。
- 密码从「安全」并入「锁定屏幕」。
- 新功能、存储从「通用」并入通用面板内部。

### 9.2 条目移动与合并

| 条目 | 现状 | 新位置 |
|---|---|---|
| 台前调度开关 | 控制中心 + 桌面与程序坞两处，无主从 | 桌面与程序坞为主入口；控制中心标快捷副本 |
| 专注模式 | 专注模式面板 + 控制中心卡片 | 专注模式为主入口；控制中心标快捷副本 |
| Siri 唤醒提示音 / 光球辉光 | App 面板 | Siri 面板 |
| 登录密码 | 密码独立面板 | 锁定屏幕 › 登录密码 |
| 新功能 | 独立面板 | 通用 › 关于 |
| 存储 | 独立面板 | 通用 › 存储 |

## 12 追加：顶栏跟随壁纸取色（2026-11-08）

排在外观面板的「菜单栏」分组里（「窗口着色」之后、「滚动与动效」之前），不改前面 6 分区 / 18 面板的结构。

### 12.1 五个新键

| 键名 | 默认值 | 控件 | 联动 / 说明 |
|---|---|---|---|
| `menubar.textColor` | `auto` | 四段：自动 / 浅色 / 深色 / 自定义 | 自动按壁纸顶部明暗算黑白里对比度更高的一边；浅色=白字，深色=深字 |
| `menubar.textColor.custom` | `#ffffff` | 颜色选择 | 仅 `custom` 档可改，其余档整行禁用 |
| `menubar.blur` | `100` | 滑块 0–100 % | 缩放系统第 3 档模糊；不透明度 100 % 时整行禁用 |
| `menubar.opacity` | `0` | 滑块 0–100 % | 顶栏底色浓度；100 % 时切实色并关闭毛玻璃 |
| `menubar.backgroundColor` | `#1c1c1e` | 颜色选择 | 仅不透明度 100 % 时可改，其余档整行禁用 |

默认值取「和改造前视觉最接近」的一档：不透明度 0、模糊 100 %、文字自动。录制中的宣传片素材不会因默认外观变化而对不上。

### 12.2 取色与兜底

- 采样源只用壁纸配置里已有的 `thumb`（48 px JPEG），不重新读 IndexedDB 原图；`thumb` 缺失时退回非 `idb:` 的图片地址。
- 只统计顶部 16 % 的平均色；结果按「壁纸类型 + 图片特征」缓存（上限 24 条），换壁纸才重算。
- 换壁纸、换壁纸类型由 `wallpaper-change` / `wallpaper-tint-change` 触发；慢采样用序号丢弃旧结果，避免旧壁纸颜色盖住新壁纸。
- 采样失败或图片不可解码时退回中性蓝灰，不会留下无底色的顶栏。
- 自动文字色用 sRGB 相对亮度算黑/白对比度，取更高的一边；黑白最高对比度恒 ≥ 4.5，因此不会出现灰字压灰底。

### 12.3 铁律与实现约束

- `backdrop-filter` 所在元素不挂 `transform`：`menubar-tint.js` 只写 CSS 变量与 `<html>` 的 data 属性，不碰顶栏变换。
- 完全不透明走 `html[data-menubar-opaque="true"]`：底色换成用户选的颜色，`backdrop-filter: none`，模糊滑杆同步禁用。
- 单色图标随墨色翻：`data-menubar-ink="black"` 时 invert 图标并去掉白字投影；`white` 时恢复投影。顶栏这套规则写在壁纸墨色规则之后，同特殊度下以顶栏为准。

### 13.2 苹果没有的条目：插在哪、为什么

- **默认应用** → 紧接「桌面与程序坞」之后。苹果把默认浏览器的设置放在「桌面与程序坞」里，本机把它独立成面板，因此贴着它的原住面板放，不另起一簇。

- **开发者** → 整条侧栏最后。同上，属补充入口，不占苹果的系统位置。
- **新功能 / 存储 / 密码**：仍是「未实现、合并进邻居面板」，不占侧栏位置（分别并入通用、锁定屏幕）。
