五分钟写第一个插件

以 mods/about/（最小完整骨架）为模板。会拆计算逻辑的看 mods/calculator/。

五步

  1. 建目录 mods/<id>/：manifest.json + index.html + style.css + script.js（+ 图标，规则见下）；
  2. 把 id 加进 src/javascripts/plugin-manager.js 的 BUILTIN_IDS（内置插件才需要；走商店分发则不用）；
  3. 在浏览器里刷新扩展新标签页：程序坞出现图标，点击开窗；
  4. 跑 node dev/static-check.mjs（键位 / 资源 / import 全量核对）；
  5. 有计算逻辑：把纯函数拆进独立文件被 entry import（冷加载的模块表特性见 冷加载）。

最小 manifest（全字段表见插件包格式）

{
  "id": "my-plugin",
  "name": "我的插件",
  "version": "1.0.0",
  "entry": "window",            // window | fullscreen
  "main": "index.html",
  "style": "style.css",
  "script": "script.js",
  "window": { "width": 420, "height": 560, "centered": true, "resizable": true },
  "permissions": []            // 哪怕不用能力也要写 []（static-check 第 7 节核对）
}

index.html（HTML 片段，不是完整文档）

<div class="window" data-window="size:420x560;resizable:false">
  <header class="titlebar" data-titlebar>
    <deskly-traffic-lights class="wintools" placement="titlebar"></deskly-traffic-lights>
    <span>我的插件</span>
  </header>
  <section class="content">
    <p data-i18n="myPlugin.title" data-i18n-fallback="我的插件">我的插件</p>
  </section>
</div>

data-window 的键（size / min / max / aspect / center / resizable / titlebar / snap / blur） 以 window-manager.js 为准；与 manifest.window 冲突时以 data-window 为准。 红绿灯的位置、能力开关与 JS 挂载 API 见窗口红绿灯。

script.js（ES Module，顶层直接 init）

import { i18n } from '../../src/javascripts/i18n.js';

i18n.registerMessagesAll({
  "zh-CN": { myPlugin: { title: "我的插件", run: "运行" } },
  en:      { myPlugin: { title: "My Plugin", run: "Run" } },
});

function init() {
  const root = document.querySelector('.window[data-plugin-id="my-plugin"]');
  // 界面逻辑
}
init();

// ★ 冷加载硬约束：全局注册必须在 plugin-unload 里释放
window.addEventListener("plugin-unload", (e) => {
  if (e.detail?.id !== "my-plugin") return;
  // 解绑 document/window 监听、清定时器、delete window.__menuActions 里你加的键
});

图标（硬规则）

  • 应用图标一律 PNG，禁止 SVG；
  • 先到 assets/icons/（含 dock/、folder/ 子目录）找，找到就复制进插件目录， manifest.icon 只写裸文件名（如 "icon.png"）——ZIP 要求插件目录自包含；
  • 库里没有合适的就不声明 icon，系统自动落 GENERIC_APP_ICON 占位图（assets/icons/dock/Launcher.png）；不引用、不凑数、不自绘。
跑通标准 程序坞出现你的图标 → 点击开窗且红绿灯可拖动/缩放 → 右上角显示「设置」齿轮可改你的设置项 → 顶栏出现你的自定义菜单 → static-check 全绿。
