# 知识库章节汇编规范（子代理共用）

## 背景
`E:\hello\StartOS\docs\iMac-2024-macOS15-知识库\` 是从苹果官方《iMac 使用手册（2024 年款 · macOS Sequoia 15）》
逐页抓取的原始语料，已转成 Markdown：

- `pages/NN-标题.md`：63 篇逐页原文转换结果（**只读，不要改**）。每篇开头两行是来源 URL 和目录章节名。
- `images/`：209 张手册原图（PNG），页面里以 `![alt](../images/xxx.png)` 引用，紧跟一行 `*图：alt*` 说明。

任务：把你负责的若干 `pages/` 文件**重新组织**成一章高质量中文知识库，输出到指定文件。

## 输出要求
1. 文件结构：
   ```
   # <章名>
   > 来源：苹果《iMac 使用手册》2024 年款 · macOS Sequoia 15 · <本页对应章节范围>
   ## <小节名>          ← 每个来源页一个小节（标题沿用手册原页名，去掉“Mac 上的”这类冗余前缀可保留语义）
   ...正文...
   ```
2. 内容密度：**这是知识库不是摘要**。操作步骤、菜单位置、快捷键、注意事项、限制条件、术语必须保留，
   用手册原话的语义，不要水化。可以合并同类项、去掉重复的“请参阅 XXX”外链（保留必要的官方链接），
   去掉苹果客服式套话。目标长度约为来源页总字数的 45%–70%。
3. 菜单路径用「」括起来（如「苹果菜单 > 系统设置 > 通用」），键名用 `Backtick`（如 `Command-Shift-5`）。
4. 表格：来源页里的 Markdown 表格（快捷键表、端口规格表等）**必须完整保留**为表格，不要拆成正文。
5. 图片：**来源页里出现的每一张不同图片都要在你的章节里出现一次**，路径保持 `../images/文件名`，
   并保留 `*图：说明*`。放在语义最合适的位置；同一小节内不要重复引用同一张图。
   正文里已经用  字符替代的苹果标志小图标不需要再引图。
6. 每个小节末尾如有实操价值，加一行 `**要点**` 或 `**注意**`（不超过 2 条），没有就不加。
7. 章末加 `## 本章速查`：把该章的快捷键、手势、菜单路径、端口规格等浓缩成表或列表。
8. 不许编造手册里没有的事实；不许写“本章将介绍”这类空话；不要写与插件对比的内容（那是后续独立任务）。

## 禁止
- 不修改 `pages/`、`images/`、`INDEX.md`、`README.md` 和其他章节文件。
- 不新增图片文件、不下载网络资源。
- 不使用 emoji。

## 交付后自检（必须做）
在你负责的所有 `pages/*.md` 里 grep 出图片文件名集合，与你输出文件里的图片集合比对，
在最终回复里报告：`来源页数 / 输出字数 / 来源图片去重数 / 已嵌入图片数 / 缺失图片文件名（应为 0）`。
