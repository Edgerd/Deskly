菜单栏状态项

菜单栏右侧、时钟之前的三个系统状态项：电池 / 音量 / 蓝牙。全部显示真实数据——没有数据就整项隐藏，不画假值。源码：src/javascripts/menubar-status.js。

三个状态项

项数据源（真数据，无装饰图）显隐
电池navigator.getBattery() 直读 + 百分比数字；没有电池 API、或桌面机返回「100% 充电中」的假状态时整项隐藏，不画假电池默认显示
音量sound.master / sound.muted（与控制中心同一个 JSON 设置槽；静音时波形熄灭）默认显示
蓝牙controlcenter.bluetooth（关闭态降透明度）默认显示

三个「在菜单栏显示」开关

模块自注册进设置中枢（owner 权威，与 controlcenter.showInMenuBar 同一套自持定义模式）：

menubar.showBattery     // 系统设置 › 控制中心面板自动出卡片（group: 菜单栏状态项）
menubar.showVolume
menubar.showBluetooth

关掉的项元素仍在 DOM 里，只是 display:none 不占位——再打开不必重新挂载。开关由设置面板驱动，与菜单栏显示双向同步。

交互与扩展

  • 点击任一状态项 → 打开控制中心面板（这些状态的「家」都在控制中心；不做「点电池开电池面板」的半吊子路径）。
  • 数据刷新订阅 settings-changed（音量 / 静音 / 蓝牙都经设置中枢写入）。
  • 加自定义状态项：往 menubar-status.js 的 ICONS + makeItem() 序列里加一项，配套注册一个 menubar.show<Key> 设置定义（组「菜单栏状态项」、pane controlcenter），数据源接进 settings-changed 或你自己的事件。 遵循「无数据就隐藏整项，不画假值」原则——battery 的 no-data 处理是现成示范。
历史收口 菜单栏右端曾经有一张无监听的 Wi-Fi 装饰图，已删除——真实 Wi-Fi 状态在控制中心面板看，不再摆死图。
