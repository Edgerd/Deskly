多语言 i18n

系统界面支持四种语言：zh-CN（中文）/ en / ja-JP / cat（萌猫语言，中文加「喵」尾）。插件自己的文案用 registerMessagesAll 注册，不要往内核语言包里塞键。源码：src/javascripts/i18n.js。

怎么用

i18n 不是全局对象，按站内惯例 import：

import { i18n } from '../../src/javascripts/i18n.js';
方法说明
t(key, fallback)点分路径取值（"myPlugin.title"）；缺失回退 fallback。每个调用都必须带字面量兜底——static-check 会核对「无兜底调用」
hasKey(key)当前语言（含插件注册文案）里有没有这个键
getSupportedLanguages()支持语言表 [{code, label}]；画语言选择器用它，别硬编码四门语言
getLanguage() / setLanguage(lang)当前代号 / 切换并持久化、重刷界面（越界代号抛错）
applyTranslations(root?)对子树里带 data-i18n 的元素就地翻译（默认扫全文）
registerMessages(lang, obj) / registerMessagesAll(byLang)注册插件自带文案，返回并入的叶子键数
onChange(fn)订阅语言切换（回调收新代号，返回退订函数；plugin-unload 里记得退订）

插件自带文案（推荐姿势）

i18n.registerMessagesAll({
  "zh-CN": { myPlugin: { title: "我的插件", run: "运行" } },
  "en":    { myPlugin: { title: "My Plugin", run: "Run" } },
  "ja-JP": { myPlugin: { title: "マイプラグイン", run: "実行" } },
  "cat":   { myPlugin: { title: "我的插件喵", run: "运行喵" } },
});
const title = i18n.t("myPlugin.title", "我的插件");   // 缺键靠 fallback，界面不会空
  • 插件文案写进独立的 pluginMessages 表，生效字典 =「内核语言包为底 + 插件包叠上」深合并： 内核重新拉包 / 切语言都不会抹掉你的键；内核改了同命名空间的某个键，也不会清空你的兄弟键。
  • 注册时机与内核加载先后无关（语言包没到位也会先建条目）。
  • 四语齐备是规约：只写两语，其余语言的用户就只能看到兜底文案。

data-i18n：HTML 里的声明式翻译

<span data-i18n="myPlugin.run" data-i18n-fallback="运行">运行</span>
  • 命中的元素被写入 textContent（不是 innerHTML）——所以标记里别放 HTML。
  • 插件 HTML 是打开时才注入的，内核挂了 MutationObserver：新出现的带 data-i18n 的节点会被就地翻译，你不用管。 如果是自己动态插入的片段、observer 还没跑到，可以手动 i18n.applyTranslations(node)。
  • 内核只认 data-i18n 与 data-i18n-fallback 两个属性。data-i18n-placeholder / data-i18n-title 没有任何内核代码读（个别插件自己补了一轮翻译才有用，不是系统能力）。JS 拼出来的文案一律走 t(key, fallback)。

构建时文案必须随语言重建

下拉选项、标签数组这类「构建时算出来」的文案，必须订阅 onChange 重建，否则永远冻在切换前的语言上。 另外，动态拼键（t("a." + x)）会被 static-check 标记——键必须是字面量，需要分支时用三目选两个字面量键。
