z-index 层级表（Z）

全站唯一 z-index 来源：src/javascripts/zindex.js。浮层只走 Z 表，窗口只走焦点栈。

两条铁律

  1. 浮层类元素（顶栏、Dock、通知、弹层、启动台、警示背板…）只取 Z 表键值， CSS 里不出现裸 z-index 字面量（窗口内部的局部堆叠除外，且必须注释说明）；
  2. 窗口的 z 只来自 window-manager 焦点栈（2050-9000 动态段）：任何地方不手写 style.zIndex 定窗口层（INT_MAX 只用于窗口内部子元素相对自身的堆叠）。 手写 z-index 与焦点栈是两套账，窗口一动就会互相压穿。

历史偏差记录 仓库自曝的 3 处裸 z-index（main.css 4000 可压动态窗口、 controlcenter.css 3000、dock.css 9999）已于 v0.2.94 全部收编入 Z 表并加 CSS 注释指向 Z 键； 启动台 9601/9602 于 v0.2.95 收编。详见仓库 dev/devdoc/z-layers.md 的「历史偏差」节。

改层级的正确姿势

  1. 改 zindex.js 一处（加键或改值）；
  2. 消费方 CSS 写 z-index: Z.<键> 的注释指向（值写死在 CSS 里、注释指键——这是站内现状， 改值时同步 CSS 注释与 z-layers.md 表）；
  3. 跑「层级体检」（顶栏调试菜单 / deep-check）核对没有裸值漏网。
