第二单元我们周围的空气

2. 硫在空气、氧气中燃烧
硫 + 氧气点燃→二氧化硫
S + O2 点燃SO2
3. 木炭充分燃烧
碳 + 氧气点燃→二氧化碳
C + O2 点燃CO2
4. 铁丝在氧气中燃烧

3Fe + 2O2 点燃Fe3O4
5. 加热高锰酸钾制取氧气
高锰酸钾加热→锰酸钾 + 二氧化锰 + 氧气

6. 过氧化氢分解制取氧气
过氧化氢二氧化锰→水 + 氧气

第五单元化学方程式

1. 镁条燃烧
镁 + 氧气点燃→氧化镁
2Mg + O2 点燃2MgO
2. 铁与硫酸铜溶液反应
铁 + 硫酸铜→硫酸亚铁 + 铜
Fe + CuSO4 = FeSO4 + Cu
3. 碳酸钠与稀盐酸反应
碳酸钠 + 盐酸→氯化钠 + 水 + 二氧化碳
Na2CO3 + 2HCl = 2NaCl + H2O + CO2↑
4. 氢气还原氧化铜
氢气 + 氧化铜加热→铜 + 水
H2 + CuO △Cu + H2O

第六单元碳和碳的氧化物

1. 碳不充分燃烧
碳 + 氧气点燃→一氧化碳
2C + O2 点燃2CO
2. 木炭还原氧化铜
碳 + 氧化铜高温→铜 + 二氧化碳
C + 2CuO 高温2Cu + CO2↑
3. 木炭还原氧化铁
碳 + 氧化铁高温→铁 + 二氧化碳
3C + 2Fe2O3 高温4Fe + 3CO2↑
4. 二氧化碳与碳高温反应
二氧化碳 + 碳高温→一氧化碳
CO2 + C 高温2CO
5. 实验室制取二氧化碳
碳酸钙 + 稀盐酸→氯化钙 + 水 + 二氧化碳
CaCO3 + 2HCl = CaCl2 + H2O + CO2↑
6. 二氧化碳通入澄清石灰水（检验二氧化碳）
二氧化碳 + 氢氧化钙→碳酸钙 + 水
CO2 + Ca(OH)2 = CaCO3↓ + H2O
7. 二氧化碳与水反应
二氧化碳 + 水→碳酸
CO2 + H2O = H2CO3
8. 碳酸分解
碳酸→水 + 二氧化碳
H2CO3 = H2O + CO2↑
9. 一氧化碳燃烧
一氧化碳 + 氧气点燃→二氧化碳
2CO + O2 点燃2CO2
10. 一氧化碳还原氧化铜
一氧化碳 + 氧化铜加热→铜 + 二氧化碳
CO + CuO △Cu + CO2
