# 第 3 章 · 桌面、菜单栏、访达、程序坞、通知、控制中心、聚焦与 Siri

## 桌面和菜单栏

首屏分三部分：*桌面*（工作区）、屏幕顶部的*菜单栏*、屏幕底部的*程序坞*。

![显示苹果菜单、App 菜单、“帮助”菜单、桌面、菜单栏、“访达”窗口、Wi-Fi 图标、“控制中心”图标、“访达”图标、“系统设置”图标以及程序坞的 Mac 屏幕。](images/S0010_DesktopFinder.webp)

**桌面。** 用于打开和使用 App、处理文件，或用「聚焦」搜索 iMac、网站等；可储存文件并用「叠放」保持井井有条。更改桌面图片：「系统设置」> 边栏「墙纸」。

**【提示】找不到指针时：** 在触控板上快速来回移动手指或快速滑动鼠标，可暂时放大鼠标指针。

**菜单栏。** 贯穿屏幕顶部。左侧是菜单，用于在 App 中选取命令、执行任务，菜单项随 App 而变化；右侧是状态图标——接入 Wi-Fi 网络、检查 Wi-Fi 状态：

![Wi-Fi 状态图标 —— 接入 Wi-Fi 网络、检查 Wi-Fi 状态。](images/IL_WiFi.webp)

检查电池的充电状态：

![电池充满图标 —— 检查电池的充电状态。](images/IL_Battery.webp)

以及打开「控制中心」、用「聚焦」搜索（图标见下文对应小节）。菜单栏图标可自定义（见「控制中心」节）。桌面可同时开多个窗口，如 FaceTime 通话窗口：

![FaceTime 通话窗口显示通话参与者通过同播共享一起聆听专辑。](images/S0107_DesktopFaceTimeSharePlayMusic.webp)

**苹果菜单。**

![苹果菜单图标（标志）。](images/IL_AppleLogo.webp)

包含经常使用的项目，始终显示在屏幕左上角；点按苹果图标即打开。

**App 菜单。** 可同时打开多个 App 和窗口。活跃 App 名以粗体显示在苹果菜单右侧，其后是该 App 独特的菜单；打开其他 App 或点按其窗口后，App 菜单与整个菜单栏随之更改。找不到命令时，先确认要用的 App 是否活跃。

**「帮助」菜单。** 在程序坞打开「访达」，点按「帮助」>「macOS 帮助」即打开《macOS 使用手册》；也可在搜索栏键入并选取建议。特定 App 的帮助：打开该 App 并点按菜单栏「帮助」。

![部分桌面，其中“帮助”菜单已打开，显示“搜索”和“macOS 帮助”菜单选项。](images/S0015_DesktopHelpMenu.webp)

**【提示】** 可把「小组件中心」的小组件添加到桌面，甚至添加 iPhone 上的小组件而无需安装相应 App（见「通知中心」节）。

## 访达

「访达」是带笑脸的蓝色图标，为 Mac 的大本营，用于整理和访问文稿、图像、影片及其他几乎所有文件。打开窗口：点按屏幕底部程序坞中的

![“访达”图标。](images/IL_FinderAppIcon.webp)

用力点按文件图标可快速查看内容，用力点按文件名可编辑名称；相关手势见手册「妙控板」一节。

![打开的“访达”窗口，以图标形式显示文件和文件夹。](images/S0011_FinderWindow.webp)

**井井有条。** Mac 已为常见内容类型创建「文稿」「图片」「应用程序」「音乐」等文件夹；新建文件夹：「文件」>「新建文件夹」。

**同步设备。** 连接 iPhone 或 iPad 等设备时，设备显示在「访达」边栏中；点按设备名称查看备份、更新、同步和恢复设备的选项。

**「访达」边栏。** 左侧边栏显示常用或想快速打开的项目：点按「iCloud 云盘」查看全部 iCloud 文稿；点按「共享」仅看你正共享和与你共享的文稿。更改边栏内容：「访达」>「设置」。

**更改查看文件和文件夹的方式。** 点按「访达」窗口顶部的弹出式菜单按钮切换视图：

![图标视图按钮。](images/IL_IconView.webp)

![列表视图按钮。](images/IL_ListView.webp)

![层级分栏视图按钮。](images/IL_ColumnView.webp)

![画廊视图按钮。](images/IL_GalleryView.webp)

即图标、列表、层级分栏、画廊四种。画廊与分栏视图显示所选文件的大预览图，便于直观辨别图像、视频片段或其他文稿，也可就地旋转或标记图像。「预览」面板：「显示」>「显示预览」；自定义显示内容：「显示」>「显示预览选项」，再按文件类型选择选项。

**【提示】** 若要在「画廊视图」显示文件名，按下 `Command-J` 并选择「显示文件名」。

![打开的“访达”窗口，处于“画廊视图”，显示了一张较大的照片，其下方是一排较小的照片，即滑动条。滑动条右侧是旋转、标记等控制。](images/S0066_GalleryView.webp)

**快速操作。** 在「画廊视图」或「分栏视图」中，点按「访达」窗口右下方的

![“更多”按钮。](images/IL_EllipsisCircle.webp)

以使用直接在「访达」中管理和编辑文件的快捷方式：用「标记」旋转、注释或裁剪图像；把多个图像和 PDF 合并为单个文件；修剪音频和视频；运行「快捷指令」创建的快捷指令；用「自动操作」工作流程做自定义操作（如加水印）。

**快速查看。** 选择文件后按 `Space` 打开。用窗口顶部按钮给 PDF 签名、修剪音视频、标记／旋转／裁剪图像，无需一一打开相应 App。「预览」或「快速查看」的「标记」还可添加供「旁白」朗读的备选图像描述。

**更快访问。** 「前往」菜单可快速前往文件夹和位置：「前往」>「实用工具」免去逐级点按；「前往」>「上层文件夹」返回嵌套文件夹的顶层；「前往」>「前往文件夹」再键入已知路径。

**要点** 不开 App 也能编辑：`Space` 唤起「快速查看」，「更多」按钮唤起快速操作。

## 程序坞

屏幕底部的程序坞保留最常用的 App 和文稿。分隔条把 App 与文件及文件夹分开：App 在左侧，文件或文件夹在右侧，最近打开的 App 显示在中间部分。

![程序坞，显示“访达”、“系统设置”以及程序坞中将 App 和文件及文件夹分隔的分隔条。](images/S0046_Dock.webp)

**打开 App 或文件。** 点按程序坞中的 App 图标；或点按程序坞中的「启动台」图标

![启动台图标。](images/IL_LaunchpadAppIcon.webp)

查看 Mac 上所有 App 后点按目标；也可用「聚焦」（菜单栏右上角）搜索 App 并直接从结果打开。

**关闭 App。** 点按打开的窗口左上角的红色圆点时，该窗口关闭但 App 仍保持打开；程序坞中打开的 App 图标下面有一个黑色圆点。

![程序坞的一部分，显示打开的 App 下面的黑色圆点。](images/S0088_DotsinDock.webp)

若要关闭 App，按住 `Control` 键点按程序坞中的 App 图标，再点按「退出」。

**添加与移除项目。** 拖移项目放到想要位置即添加；把它拖出程序坞只是移除入口，不会从 Mac 移除。

**查看 Mac 上所有打开的内容。** 按下键盘上的调度中心键

![调度中心键。](images/IL_MissionControl.webp)

或用三指轻扫触控板打开调度中心，查看并在打开的窗口、桌面空间、全屏幕显示的 App 之间切换；也可把「调度中心」图标

![调度中心 App 图标。](images/IL_MissionControlAppIcon.webp)

添加到程序坞。

**查看一个 App 中所有打开的窗口。** 在程序坞中用力点按该 App（点按然后更用力按下）。

**【提示】**「系统设置」>「桌面与程序坞」可更改程序坞的外观和行为：调整大小、移到屏幕左侧或右侧、设为不使用时隐藏等。

**注意** 关窗口不等于退 App，运行状态看图标下方黑色圆点；拖出程序坞只移除入口，不删除文件。

## 「通知中心」

「通知中心」于一处显示所有重要信息、提醒事项和小组件：了解日历日程、股市、天气等，并稍后查看未读的电子邮件、信息、提醒事项。

**打开。** 点按屏幕右上方的日期或时间，或用双指从触控板右边缘向左轻扫；向下滚动查看更多。

![“通知中心”显示了通知以及“日历”、“天气”、“时钟”和“屏幕使用时间”的小组件。](images/S0056_DesktopNotificationCenter.webp)

**与通知交互。** 可回复电子邮件、收听最新播客或查看日历日程详情；点按通知右上角的箭头查看选项、执行操作或获取更多信息。

**设定通知设置。** 「系统设置」>「通知」：选择要查看的通知，包括是否要在 Mac 上查看 iPhone 通知；通知按时间先后排列。

**暂停通知以专注于工作。** 工作、用餐或不想被打扰时，专注模式会自动过滤通知，只显示你指定的通知；它会暂停所有通知或仅允许特定通知显示，并通过「信息」中的状态告诉联系人你的通知已静音。设置：「系统设置」> 边栏「专注模式」。开关：点按菜单栏的「控制中心」图标 >「专注模式」部分 > 选取一种模式。可自定义允许来自特定联系人或 App、电话或临近日程等的通知，可在设备间共享专注模式，也可用专注模式过滤条件隐藏「日历」「信息」等 App 中的干扰内容。

**自定义小组件。** 点按底部「编辑小组件」查看小组件中心，添加、移除或重新排列小组件。iPhone 和 Mac 登录相同 Apple 账户时，可把 iPhone 小组件加到桌面而无需在 Mac 安装相应 App；新小组件可拖到桌面任意位置或拖入「通知中心」；还可添加来自 App Store 的第三方小组件。

## 「控制中心」

「控制中心」集中显示重要设置，让你从菜单栏直接访问最常用控制：蓝牙、隔空投送、屏幕镜像、专注模式、亮度和音量。点按屏幕右上角的

![“控制中心”状态菜单。](images/IL_ControlCenter.webp)

以打开「控制中心」。

![Mac 上“控制中心”的放大视图。](images/S0028_DesktopControlCenter.webp)

**点按可查看更多选项。** 点按某个按钮查看更多选项，如点按 Wi-Fi 按钮（图标见「桌面和菜单栏」节）查看首选网络、其他网络或打开 Wi-Fi 设置；再次点按「控制中心」图标返回主视图。

**管理桌面。** 用「台前调度」自动整理 App 和窗口并快速切换；还可将 App 归为一组，建立适合自身工作流程的工作空间。

**监视麦克风。** 麦克风正在使用时，「控制中心」顶部出现录音指示器，让你知晓 App 是否可访问麦克风，从而提高 Mac 的安全性和隐私。

**置顶常用项目。** 把常用项目从「控制中心」拖到菜单栏置顶，点按一下即可访问。更改菜单栏显示内容：「系统设置」>「控制中心」> 点按各项旁的弹出式菜单 >「在菜单栏显示」，并可预览该控制显示在菜单栏的哪个位置。某些项目无法添加到「控制中心」或菜单栏，或从中移除。

![“控制中心”设置窗口。](images/S0082_DesktopControlCenterSettings.webp)

**【提示】** 若要快速从菜单栏移除项目，按住 `Command` 键并将项目拖出菜单栏。

## 「聚焦」

使用「聚焦」

![“聚焦”图标。](images/IL_Spotlight.webp)

可轻松查找 iMac 上的所有内容：图像、文稿、联系人、日历日程、电子邮件；也可打开 App 或执行快速操作（如开始专注模式）。

**搜索任何内容。** 点按屏幕右上方的「聚焦」图标后开始键入，或按键盘「聚焦」键 (`F4`)。可借助「实况文本」搜索图像中的文本（在指定语言中可用）。

**【提示】** 按下 `Command–空格` 键来显示或隐藏「聚焦」搜索栏。

![显示“马匹照片”搜索结果的“聚焦”窗口。](images/S0006_Spotlight.webp)

**打开 App。** 在「聚焦」中输入 App 名称，然后按下 `Return` 键。

**执行快速操作。** 打开「聚焦」搜索想执行的操作，即可运行快捷指令、打开勿扰模式、设置闹钟等。

**转换货币、温度和度量单位。** 输入货币（如 `$`、`€` 或 `¥`）和金额，按下 `Return` 键获取转换后的值列表；或者指定单位转换的度量单位。

![“聚焦”搜索显示 25 磅转换成千克、短吨、盎司、克和毫克。](images/S0016_SpotlightTimer.webp)

**缩小搜索范围。** 可包括或排除特定文件夹、磁盘或信息类型（如电子邮件、信息）：点按「系统设置」中的「聚焦」，前往「搜索结果」，选择或取消选择类别。

**使用 Siri 建议。** 搜索时「Siri 建议」提供维基百科文章、网页搜索结果、新闻、体育、天气、股票、影片及其他来源的信息。若只想搜索 iMac 上的项目，在同一页取消选择「搜索结果」下方的「Siri 建议」。

## Siri

在 iMac 上用 Siri 执行日常任务、查找信息：计划会议、更改设置、获得答案、发送信息、拨打电话、把项目加到日历。打开 Siri 设置中的「听取」后，说「嘿 Siri」或「Siri」即可激活并随即说出请求。

**Siri 请求示例：**

- “从这里怎么回家”
- “珠穆朗玛峰有多高”
- “新建日常采购清单”
- “显示我的提醒事项。”
- “巴黎现在几点？”

*【注】* 使用 Siri 必须接入互联网；Siri 不支持所有语言、并非在所有地区都可用，功能可能会不同。

**打开 Siri。** 打开「系统设置」，点按边栏中的「Apple 智能与 Siri」

![Apple 智能与 Siri 设置项图标。](images/IL_AppleIntelligenceAppIcon.webp)

（或「Siri」

![Siri 设置项图标。](images/AppIconTopic_Siri.webp)

），打开 Siri 并点按「启用」。若设置期间已启用 Siri 且配有触控 ID 的妙控键盘，可按住键盘上的听写／Siri 键 (`F5`)

![听写／Siri（麦克风）键。](images/IL_Microphone.webp)

打开 Siri。其他可自定义项：使用的语言与声音、是否在菜单栏显示 Siri。

**「嘿 Siri」或「Siri」。** 在 iMac 上只需说出即可获回复：在同一页面点按「听取」旁的弹出式菜单选取选项，再按屏幕指示完成设置。

**激活 Siri。** 点按菜单栏中的

![启用 Apple 智能后的 Siri 图标。](images/IL_SiriAppleIntelligence.webp)

或

![Siri 图标。](images/IL_Siri.webp)

也可按住妙控键盘的听写／Siri 键 (`F5`)，或使用 Siri 设置中选择的键盘快捷键。想深入了解用法，随时问“你能做什么？”，或参阅 [Apple Siri 网站](https://www.apple.com/cn/siri/)。

**键入以使用 Siri。** 用键入代替说话：「系统设置」>「辅助功能」>「Siri」，打开「键入以使用 Siri」。Apple 智能已打开时可直接键入请求，只需点按上文的 Siri 图标。

*【注】* Apple 智能并非在所有语言或地区中都可用；设备、语言与地区的支持情况见 Apple 支持文章 [如何获取 Apple 智能](https://support.apple.com/121115)。

**显示回答。** 在同一页面点按「Siri 回答」，打开「始终显示 Siri 的回答」；也可打开「始终显示你对 Siri 说的话」让 Siri 转写你的请求。

**更改声音。** 在同一页面从「声音」菜单中选取一个选项。

## 本章速查

### 键盘快捷键

| 按键 | 作用 |
|---|---|
| `Command–空格` | 显示或隐藏「聚焦」搜索栏 |
| `F4` 聚焦键 | 打开「聚焦」 |
| `F5` 听写／Siri 键（按住） | 打开 Siri；需触控 ID 妙控键盘且设置期间已启用 |
| 调度中心键 | 查看窗口、桌面空间与全屏幕 App |
| `Space` | 对选中文件打开「快速查看」 |
| `Command-J` | 「访达」查看选项；画廊视图显示文件名 |
| `Return` | 「聚焦」打开匹配 App；取货币／单位换算结果 |
| `Control` + 点按程序坞 App 图标 | 点按「退出」关闭 App |
| `Command` + 拖出菜单栏项目 | 从菜单栏移除该项目 |
| 自定义键 | Siri 设置中自选的激活快捷键 |

### 触控板与点按手势

| 手势 | 作用 |
|---|---|
| 双指从触控板右边缘向左轻扫 | 打开「通知中心」 |
| 三指轻扫 | 打开调度中心 |
| 用力点按文件图标（点按后更用力按） | 快速查看内容 |
| 用力点按文件名 | 重命名文件 |
| 用力点按程序坞中的 App | 查看该 App 所有打开的窗口 |
| 触控板上快速来回移动手指／滑动鼠标 | 暂时放大鼠标指针 |

### 界面元素与位置

| 元素 | 位置与操作 |
|---|---|
| 苹果菜单 | 屏幕左上角常驻；点按苹果图标 |
| App 菜单 | 苹果菜单右侧，活跃 App 名粗体；菜单随活跃 App 更换 |
| 「帮助」菜单 | 菜单栏内；>「macOS 帮助」或键入搜索 |

| 启动台 | 程序坞内；查看全部 App |
| 「访达」 | 程序坞蓝色笑脸图标；左为边栏，顶部为视图菜单，右下为「更多」按钮 |
| 「通知中心」 | 右上方日期／时间处；点按或双指左扫 |
| 「控制中心」 | 右上角；点按打开，再点按返回主视图 |
| 「聚焦」 | 菜单栏右上角；图标、`F4` 或 `Command–空格` |

### 菜单与设置路径

- 桌面图片：「系统设置」> 边栏「墙纸」；桌面文件整理：「叠放」
- 新建文件夹：「文件」>「新建文件夹」；边栏内容：「访达」>「设置」
- 预览面板：「显示」>「显示预览」／「显示预览选项」
- 直达位置：「前往」>「实用工具」／「上层文件夹」／「前往文件夹」
- 程序坞大小与位置：「系统设置」>「桌面与程序坞」
- 通知（含 iPhone 通知）：「系统设置」>「通知」
- 专注模式：「系统设置」> 边栏「专注模式」；开关：「控制中心」>「专注模式」
- 小组件：「通知中心」底部「编辑小组件」> 小组件中心
- 菜单栏置顶：「系统设置」>「控制中心」> 弹出式菜单 >「在菜单栏显示」
- 「聚焦」结果类别：「系统设置」>「聚焦」>「搜索结果」（含「Siri 建议」）
- Siri「启用／听取／Siri 回答／声音」：「系统设置」>「Apple 智能与 Siri」（或「Siri」）
- 键入以使用 Siri：「系统设置」>「辅助功能」>「Siri」
