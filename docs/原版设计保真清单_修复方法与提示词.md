### F-01 · 菜单栏右侧状态项集合与原版不符

**原版设计**（手册·桌面和菜单栏）：菜单栏右侧是**状态图标**——Wi-Fi（接入网络/看状态）、电池（充电状态）、「控制中心」、「聚焦」，且可自定义增减。参考图 `docs/iMac-2024-macOS15-知识库/images/S0010_DesktopFinder.png`、`IL_WiFi.png`、`IL_Battery.png`。

**现状**：`src/javascripts/finderbar.js:461` 的 `appControl` 只有 `["switch.2","magnifyingglass","wifi"]` 三项，其中 `wifi` 是无监听的装饰图；电池数据其实已用 `navigator.getBattery()` 真读进 `state.battery`，但 `src/javascripts/controlcenter.js:855` 的注释直说"本次不渲染电池卡片"，`SVG.battery` 零引用。音量/蓝牙在菜单栏完全没有。判定：**部分实现 + 假象**。

**修复方法**
1. 把状态项做成声明式列表（id / 图标 / 点击行为 / 是否可隐藏），替换 `appControl` 硬编码数组。
2. 电池：消费已有的 `state.battery`，充电态与低电量态用不同图形；无电池（台式机/不支持）时不显示该项。
3. 音量、蓝牙：点击展开对应控制中心模块（与 F-20 共用二级面板）。
4. Wi-Fi 图必须可点（打开控制中心 Wi-Fi 二级面板），或按 F-33 的降级话术处理。
