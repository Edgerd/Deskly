# 浏览器主页插件 — 优化版分段开发提示词（macOS 版）

> 本项目为 macOS 风格网页起始页，基于当前 Webintosh 项目（网页版 macOS Sequoia）改造而来。基于最新浏览器 API、Apple HIG 人机界面设计规范、macOS 设计语言及前端安全最佳实践整理。本提示词适用于将 Webintosh 项目改造为浏览器主页插件（起始页）。

---

## 📋 项目记忆（已锁定，不可更改）

### 一、核心定位

- 浏览器主页插件，模拟 **macOS 桌面体验**（起始页/新标签页）。
- 支持 **macOS Sequoia 浅色 / macOS Sequoia 深色 / 自动（跟随系统）** 三种主题风格（后续可拓展，如 macOS Sonoma）。
- 支持 **Mod 扩展系统**，内建应用商店。
- 支持多语言：中文、English、日本語、萌猫语言。

### 二、技术架构

- **技术栈**：纯 HTML + CSS + JavaScript（无框架）。
- **图标资源**：项目内置的 `.svg` / `.png` 图标文件，存放在 `./assets/icons/` 目录下，通过相对路径引用。
- **虚拟文件系统**：混合模式（IndexedDB 模拟 + File System Access API 用户授权挂载真实文件夹）。
- **应用商店**：内置源 `.zip` 包，内含插件 JSON 描述（插件名、版本、下载链接及密码）。
- **书签集成**：使用 `chrome.bookmarks` API 读取浏览器收藏夹（Chrome/Edge 支持，其他浏览器降级）。
- **多窗口环境**：基于现有 Webintosh 的窗口系统（Finderbar 菜单栏 + Dock 栏 + 独立窗口应用）。

### 三、功能模块划分

| 模块 | 说明 |
|------|------|
| **桌面层** | 图标（访达、网站快捷方式、内建应用），网格/自由拖拽双模式 |
| **菜单栏层** | Apple 菜单、活动应用菜单、系统状态图标（时间/日期/网络/控制中心） |
| **Dock 层** | 应用图标、运行指示器、图标放大动画、启动台、废纸篓、自动隐藏 |
| **启动台层** | 全屏应用网格、顶部搜索框、应用图标打开/关闭 |
| **窗口管理层** | 打开/关闭/最小化动画（Genie、缩放、淡入淡出）、拖拽、层级管理 |
| **访达层（虚拟文件系统）** | 访达（虚拟 Root + 映射下载/文档/图片/收藏夹） |
| **应用商店层** | 本地源 + 脚本源（JSON），拖放安装 + 自动解压注册 |
| **设置层** | 主题、壁纸（本地上传 + Bing 壁纸）、布局、性能模式、语言、小组件开关 |
| **内建应用** | 计算器、备忘录、文本编辑、图片浏览器、视频播放器、插件编辑器（VS Code 嵌入） |
| **Mod 系统** | 插件加载、注册、卸载、依赖管理 |

### 四、设计原则

1. **避免 AI 审美**：所有 UI 严格复刻 macOS 原生风格，不加入"现代化"的过度设计。
2. **极致复刻**：macOS Sequoia 的毛玻璃（Vibrancy/Backdrop）、半透明材质、圆角与阴影均需忠实还原。
3. **非线性动画**：所有弹出/关闭动画使用 `cubic-bezier()` 缓动函数，避免机械感。
4. **性能优先**：提供性能模式开关，低端设备自动降级。
5. **安全第一**：Mod 插件必须使用沙箱 iframe 运行，限制 DOM/网络/存储权限，仅通过 `postMessage` 与宿主通信。

### 阶段 1：菜单栏 + Dock 栏 + 桌面图标（首个可交互版本）

> **目标**：实现菜单栏（Apple 菜单 + 应用菜单 + 系统状态）、Dock 栏（图标放大 + 运行指示器）和桌面图标（网格排列 + 自由拖拽），这是 **0.1.0** 的核心交付。

**提示词**：

```
请实现浏览器主页插件的菜单栏、Dock 栏和桌面图标功能，具体要求如下：

## 一、桌面图标

1. 默认显示三个图标：
   - "访达"（虚拟文件系统入口）
   - "废纸篓"（占位，功能后续实现）

   - 使用 assets/icons/ 目录下的 svg/png 文件（通过相对路径引用）。

   - 图标下方显示名称，字体按主题使用 SF Pro / PingFang SC。

1. 顶部菜单栏由三部分组成：

   - 右侧：系统状态图标（时间、日期、网络、音量、控制中心等）。

2. 菜单栏行为：
   - 点击 Apple 菜单或应用菜单项弹出下拉菜单，点击菜单外部自动关闭。
   - 应用菜单随当前置顶应用动态切换（复用 Webintosh 现有 finderbar.js 逻辑）。

3. 菜单栏毛玻璃效果：
   - 浅色/深色主题均使用半透明毛玻璃背景（backdrop-filter: blur() + 半透明 rgba）。
   - 菜单栏背景色随主题变量变化。

## 三、Dock 栏

1. Dock 位于底部，默认显示常用应用：
   - 访达、启动台、Safari 浏览器、邮件、地图、照片、备忘录、系统设置、废纸篓。
   - 左侧为应用图标区，右侧为废纸篓（中间以分隔线隔开）。

2. 图标放大动画：
   - 鼠标悬停 Dock 时，图标随距离产生平滑放大效果（复用现有 DockAnimation 逻辑）。
   - 放大使用 transform 或 width 过渡，配合非线性缓动函数。

3. 运行指示器：
   - 正在运行的应用图标下方显示小圆点（运行指示器）。
   - 点击 Dock 图标可打开/切换/最小化应用。

4. 启动台：
   - Dock 中的"启动台"图标打开全屏应用网格，点击可启动应用。
   - 启动台打开/关闭带缩放淡入动画。

5. 自动隐藏：
   - 设置中可开关 Dock 自动隐藏，鼠标移到底部时呼出，离开后隐藏。

### 阶段 3：窗口管理器 + 动画系统

> **目标**：实现应用窗口系统，包括打开/关闭/最小化动画、窗口拖拽、窗口层级管理。

**提示词**：

```
请实现窗口管理器系统，具体要求如下：

## 一、窗口基础功能

1. 每个应用打开时显示在一个独立窗口中。
2. 窗口包含：标题栏（标题文字 + 关闭/最小化/最大化按钮）、内容区域。
3. 窗口可拖拽移动（拖拽标题栏，使用 pointer events + setPointerCapture）。
4. 窗口可调整大小（拖拽右下角或边框，最小 240x160px）。
5. 窗口层级管理：点击窗口使其置于最前，使用 z-index 管理，最前窗口加 --window-active-shadow。
6. 窗口关闭时播放关闭动画，动画结束后从 DOM 移除。

## 二、窗口动画

1. 动画类型（macOS 风格）：
   - **Genie 效果（神奇缩放）**：窗口缩放 + 弧形扭曲效果，类似 macOS 最小化（使用 canvas 或 SVG 路径动画实现曲线变形）。
   - **缩放效果（Scale）**：窗口从小到大展开（transform: scale(0.8) → scale(1) + opacity）。
   - **淡入淡出（Fade）**：透明度渐变。
2. 窗口默认动画为小幅度的淡出淡入。
3. 最小化动画：窗口缩小至 Dock 图标位置（Genie 效果）。
4. 打开动画从 Dock 图标位置展开。
5. 所有动画使用非线性缓动函数 cubic-bezier(0.16, 1, 0.3, 1)。

## 三、窗口样式跟随主题
- 浅色主题：窗口为半透明毛玻璃（Vibrancy），标题栏为浅灰半透明，按钮为红黄绿。
- 深色主题：窗口为深色半透明毛玻璃，标题栏为深灰半透明。

## 四、性能优化

```

1. 内置源（本地源）：
   - 从插件内置的 store/source.zip 文件加载。

```json
{
  "id": "plugin_id",

  "version": "1.0.0",
  "main": "index.html",

- 必须使用 sandbox="allow-scripts allow-same-origin" 等最小权限。
- 插件无法直接访问父页面 DOM，通过 postMessage 与宿主通信。
- 宿主提供受限 API：读取/写入虚拟文件系统、打开窗口、显示通知。

## 🔧 技术规范补充说明

### 浏览器兼容性

| API / 技术 | Chrome | Edge | Firefox | Safari |
|------------|--------|------|---------|--------|
| `backdrop-filter` | ✅ 76+ | ✅ 79+ | ✅ 103+ | ✅ 15.4+ |
| File System Access API | ✅ 86+ | ✅ 86+ | ❌ | ❌ |
| `chrome.bookmarks` API (MV3) | ✅ | ✅ | ⚠️ 需 WebExtensions 兼容层 | ❌ |
| CSS `cubic-bezier()` | ✅ | ✅ | ✅ | ✅ |
| JSZip | ✅ | ✅ | ✅ | ✅ |
| Monaco Editor (CDN) | ✅ | ✅ | ✅ | ✅ |

### 性能建议

- `backdrop-filter` 会触发 GPU 加速，但模糊半径过大会影响性能，建议控制在 `blur(10px)` 到 `blur(30px)` 之间。
- 毛玻璃（Vibrancy）用于菜单栏、Dock、窗口等上层表面，避免大面积使用。
- 窗口数量超过 5 个时自动降低模糊强度。
- 使用 `will-change: transform, opacity` 优化动画性能，动画结束后移除。

### 安全建议

- Mod 插件必须使用 `sandbox="allow-scripts"` iframe 运行。
- 插件与宿主通信仅通过 `postMessage`，并严格校验 event.origin。
- 插件 manifest 必须声明所需权限，未声明的 API 拒绝访问。
- 网络请求敏感操作（如下载）需用户确认，避免静默执行。
