```
┌─────────────────────────────────────────────┐
│              应用层（插件窗口）              │
│  访达 / 计算器 / 系统设置 / 关于本机 / 商店  │
└─────────────────────────────────────────────┘
┌─────────────────────────────────────────────┐
│               插件管理器                     │
│   注册表 · 冷加载 · 注入 · ZIP 安装          │
└─────────────────────────────────────────────┘

│              窗口 / 桌面层                    │

```

## 模块职责

| 模块 | 职责 |
|------|------|
| [plugin-manager.js](../../src/javascripts/plugin-manager.js) | 插件注册表、冷加载、注入、ZIP 安装接口 |
| [window.js](../../src/javascripts/window.js) | 窗口创建/拖拽/缩放/关闭/全屏/置顶 |
| [dock.js](../../src/javascripts/dock.js) | 程序坞图标、启动、右键菜单、缩放动画 |
| [finderbar.js](../../src/javascripts/finderbar.js) | 顶部菜单栏、应用菜单、系统状态 |
| [app-store.js](../../src/javascripts/app-store.js) | 应用商店渲染、搜索、ZIP 安装逻辑 |
| [main.js](../../src/javascripts/main.js) | 入口，仅串联初始化，不写业务逻辑 |

## 运行模型

- **主文档注入**：插件窗口以 HTML 片段注入主文档，保留了 `document.querySelector` 的访问方式，应用内部 DOM 逻辑几乎不改。
- **窗口控制集中**：窗口的拖拽/缩放/关闭/全屏/置顶统一由 `window.js` 负责，插件不重复实现。
- **插件自包含**：每个插件只依赖 `mods/{id}/` 目录内的文件，根资源通过 `../../` 相对路径引用。

## 关键决策

1. **冷启动**：启动时只拉取各插件 `manifest.json` 建立注册表，不加载任何界面内容。
2. **点击加载**：点击已注册插件时才并行拉取 `index.html` / `style.css` / `script.js`。
3. **Safari 例外**：Safari 保持原生非插件方式，不转换为插件包。
4. **安全边界**：插件通过 `postMessage` 与宿主通信，可扩展为沙箱 iframe 运行。
