表面：模糊与可读文字

backdrop-filter 只有一个来源：系统令牌。裸 blur(px) 会被 static-check 判失败。

模糊令牌（CSS 侧常用路径）

backdrop-filter: blur(var(--surface-blur-3));   /* 等级 0-4：关闭/极轻/轻柔/标准/浓重 → 0/4/8/12/18px */
color: var(--surface-text);                     /* 主题面板档 */
color: var(--surface-text-wallpaper);           /* 墙纸档 */
令牌用途
--surface-blur-1…5模糊半径（等级由系统统一分配，用户「模糊等级」设置改的是这套）
--surface-text*主题面板档文字（判定输入 effectiveBase().panel；菜单/弹层/提示条不吃墙纸着色）
--surface-text-wallpaper*墙纸档（背后就是墙纸的表面：全屏浮层、开墙纸着色时的侧栏/控制中心/预览 chip）

切档不是 JS 登记，而是样式表里一条可复制的配方：在 html[data-wallpaper-tint="on"] 的规则里把四条 --surface-text* 指向 --surface-text-wallpaper*（自定义属性沿继承树生效）。

带侧栏的窗口：分两块表面

  • 窗口根 background: transparent、实色只铺内容区、边栏用半透明档做真毛玻璃 （参照 mods/finder/style.css）；
  • 根上铺实色 = 在边栏背后垫平色板，backdrop-filter 只是糊自家底板；
  • 别在窗口根写 isolation: isolate——它把根变成 backdrop root，采样范围被截进窗口内部。

墙纸着色：浓度必须真的乘上

每条墙纸着色规则的固有浓度写成 calc(<固有浓度> * var(--tint-strength))， 颜色只走 var(--tint-rgb) / var(--tint-color) 那条链。没乘因子或绕过链直接读 --window-tint-rgb 都会被 static-check 5b 节拦下（否则「着色浓度」滑块拖着真实界面不动）。

__surface 接口

接口说明
getLevel()当前等级（0-4）；存储值非法回落 3
setLevel(0..4)写 appearance.blurLevel，返回布尔（越界被中枢钳制不拒绝）
levels()5 条 {value, label, unit}
token(role)返回 var(--surface-blur-N) 字符串（role 钳 1-5，缺省 3）
apply(el, {role})给「自己底色和全局不一样」的浮层登记局部表面（按它底色算局部四支文字令牌），返回注销函数；被墙纸染深的侧栏不走这里（那是样式表配方）
apply(el, {over:"wallpaper"})「这块表面的背景就是墙纸」→ 推导改走墙纸档（启动台/预览/锁屏类）

等级写入走设置中枢（广播 settings-changed），系统设置里改 / 代码里改两边不会各说各话。

逃生舱（确实要一个阶梯表达不了的模糊值）

.my-odd-surface { --surface-blur: 26px; }   /* 行尾必须带注释：/* 逃生舱：<理由> */ */

机器门禁（static-check「模糊必须走系统令牌」节）扫 blur(<数字>px) 字面量与 「有 blur 但没引用 var(--surface-blur」，覆盖 assets/stylesheets/**、mods/**、 src/** 的 .css 与 .js（JS 里拼样式串写裸 px 一样会红）。blurPx 是 lint 盲区 （内联样式里落 --surface-blur: 26px，源码没有 blur( 文本）——但代价一分没少：用户等级对它照样无感。
