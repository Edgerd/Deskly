总览与架构

Deskly 是一个运行在 Chrome / Edge 新标签页里的 macOS Sequoia 桌面（纯 HTML/CSS/JS，MV3，零框架零构建）。本站是插件开发者手册：写 mod、声明能力、接入系统接口。

它是什么，不是什么

是不是
Chrome/Edge 扩展（MV3，script-src 'self'，新标签页里启动一整套桌面）不是 iframe 应用集合：13 个 mod 全部注入到宿主文档里跑（plugin-manager fetch + 注入），共享同一份 DOM
window.Deskly 是受权限门禁的能力入口（fs/apps/bus/settings/meta）它不是沙箱边界：mod 跑在宿主主文档里，能碰全页 DOM；安全边界 = manifest.permissions 声明 + 设置/日志/层级等规约
冷加载：启动只 fetch 14 份 manifest.json，点击才拉三件资源没有构建链、没有 npm、没有打包器；开发自检是 Node 脚本（见 dev-tools）

四层结构（改代码前先认清自己在哪层）

层位置内容改动约束
ui/ 框架src/javascripts/ui/ + assets/stylesheets/ui/菜单栏、窗口、弹窗、浮层、通知、右键菜单、桌面图标共用语义跨 mod 复用；样式只走系统令牌
mods/ 应用mods/{id}/（13 个内置插件）每个插件 = manifest + index.html + style.css + script.js + icon.png自包含目录，可整体打成 ZIP 分发
src/ 内核src/javascripts/（52+ 模块）+ assets/stylesheets/（main/dock/finderbar）程序坞、启动台、控制中心、设置中枢、日志、OSFS、层级表、i18n…mod 通过 import 与 window.__* 消费，不反改
assets/ 资源assets/icons|images|svgs|locales图标库、界面图、语言包（zh-CN/en/ja-JP/cat 四语）图标一律 PNG；运行时文件名必须 ASCII

开发流程（最短路径）

  1. 五分钟写第一个插件：抄 mods/about/ 骨架 → 改 manifest → 加进 BUILTIN_IDS → 自检；
  2. 要系统能力时查 window.Deskly 与 事件地图，能力名写进 manifest.permissions；
  3. 样式只写模糊令牌与文字令牌，红线清单逐条过；
  4. 收尾跑 static-check / deep-check / settings-fulltest，全绿再提。
扩展本站 新增一篇文档 = 在 guides/、api/ 或 reference/ 下加一个 HTML（<body data-page data-base>）+ 在 assets/pages.js 注册一条。侧栏 / 顶栏 / 上下页导航 / 本页目录全部自动生成。详见 README.md。
