设置中枢 __settings

唯一设置读写入口：define / get / set / subscribe，系统设置面板自动渲染。

键名与存储槽

键形如 owner.key；槽名由 owner 派生（webstartos_<owner> 一类）—— 不要手写第三个 localStorage 键。owner 模块的既有读法（如 === "on"）决定了落盘形态。

类型、校验与序列化（四种）

type要点
boolean落盘 "on"/"off"（owner 读法所定）；读回 on/true/1、off/false/0 都认。 未注册的裸键例外：写 "true"/"false" 读回还原成布尔。想让界面认出你的键就先 define。
numbermin/max/step：超界不拒绝而是钳到边界再按 step 取整，返回钳后值。
string可配 values 白名单：不在候选内的写入直接拒绝（reason 形如「取值 neon 不在候选值 light / dark / auto 内」）。
json对象或 JSON 文本；坏文本被拒；对象默认值与存储值浅合并（新版新增字段自动带默认值）。

set() 返回信封：三种失败要分开处理

字段含义
ok是否通过校验；false 时 value 是当前值（不是你传的）
value校验/钳制后真正生效的值
persisted是否写进 localStorage；false = 本次会话能用，刷新回退
changed是否与旧值不同；同值写入不广播不记日志
reason仅拒绝时出现（中文说明，同时进 __log 的 error）

define / defineMany（插件注册自己的设置项）

__settings.defineMany([
  { key: "myPlugin.enabled", type: "boolean", default: true, owner: "myPlugin", pane: "plugins",
    label: "启用我的插件", hint: "关闭后不再注入任何界面", control: "switch", group: "我的插件", order: 10 },
  { key: "myPlugin.opacity", type: "number", default: 0.8, min: 0.2, max: 1, step: 0.05,
    owner: "myPlugin", pane: "plugins", label: "浮层不透明度", control: "slider",
    format: "fixed1", group: "我的插件", order: 20 },
]);
  • pane: "plugins" 归到系统设置「插件」面板：收录规则 = owner 不是 system、pane 缺省或 plugins、没被 hidden； 逐行由 autoRow() 按 control 生成控件（switch / slider / segmented / …）。
  • 三条生命周期硬约束：① 在插件初始化时就 define（注册了才出现在设置里）； ② define 必须可重复调用（入口脚本每次打开都重跑，同名定义做字段合并，天然幂等；别在 apply 闭包里捕外部状态）； ③ 没有撤销接口——卸载后定义仍留表里，要「关掉即隐藏」用 hidden 或在 apply 里兜缺失状态。

event 与 apply：二选一

写法行为
apply: (v, {previous, persisted, source}) => {}落盘后由中枢调用；抛错只记 error 不打断写入。owner 自己会把值应用到真实状态时用。
event: "my-change"中枢在 window 上补发旧格式 CustomEvent，detail 是序列化字符串（json 例外给对象）。owner 只有监听没有 setter 的历史模块用（dock 7 项 / 启动台 2 项 / Siri 1 项）。
同一个定义里别同时写：owner 的 apply 里往往自己就 dispatchEvent，中枢再补发一次 → 同一事件派发两遍、监听方执行两遍。新插件两者都不必写：需要即时生效就订阅 settings-changed。

订阅变更

const off = __settings.on("myPlugin.opacity", (value, detail) => repaint(value));
// 或接口级：__settings.subscribe(d => { if (d.key.startsWith("myPlugin.")) ...; })
// 或 document 统一事件：detail = {key, value, previous, persisted, type}（对象）
document.addEventListener("settings-changed", onChanged);
  • 同值写入不广播（别指望它做心跳）；opts.silent 批量恢复也不广播；
  • 必须在 plugin-unload 里退订（入口脚本每次重跑，模块表不回收旧实例，订阅连同捕获的已卸载 DOM 会永久累积）。

别把密钥放进设置

snapshot() 会把已注册项的原始存储文本整份导出（备份/诊断用）， settings-changed 的 detail 与 __log 的写入记录同样带值。仓库示范（锁屏口令）： 哈希与盐存设置中枢之外的自有槽，SHA-256(盐:口令) 才落盘，日志里既无明文也无摘要（lock.js）。
