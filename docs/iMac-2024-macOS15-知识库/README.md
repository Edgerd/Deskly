## 怎么查

- 想知道某个快捷键 → [第 7 章快捷键总表](07-获得答案.md)，或各章末「本章速查」。
- 想知道某个界面元素叫什么、能做什么 → 第 3 章（桌面/菜单栏/访达/程序坞/通知/控制中心/聚焦/Siri）与第 4 章（窗口管理）。
- 想核对某个功能的确切原文表述 → 用 [INDEX.md](INDEX.md) 定位到 `pages/` 对应页，每篇开头都带官方原文链接。
- 图片找不到出处时：文件名保留了苹果原始资源名（如 `S0115_DesktopSplitView.png`、`P0002_iMacNPorts4.png`），可在 `pages/` 里 grep。

## 数据口径与已知边界

1. 仅覆盖 **2024 年款 24 英寸 iMac + macOS Sequoia 15** 这一版手册；同一站点还有 2023（Sonoma 14）、2025（Tahoe 26）等版本，未抓取。
2. 手册正文中的「请参阅」大量指向 **《Mac 使用手册》（mac-help）** 与各类 Apple 支持文章（如 FileVault、防火墙、Gatekeeper、锁定模式、系统设置逐面板细节），这些页面**不在本手册内**，故知识库也未包含；需要时须另取 `guide/mac-help` 作为来源。
3. 图片只下载了浅色模式版本；官方 HTML 里的 `~dark` 深色变体（同一图的暗色版）已刻意跳过，未计入 209 张。
4. 第 8 章的法务文本做了压缩（同一段落的法语/西语/葡语复本、62 项商标逐条罗列），硬性数值与警告条目全部保留。
5. `pages/` 是脚本直出的逐页转换件，保留官方措辞与链接，作为「事实底片」存在；正文以 8 章文件为准。
